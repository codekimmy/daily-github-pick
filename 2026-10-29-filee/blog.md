## 1. 이런 경험 있으시죠?

- 거래처에서 **.hwp 파일**을 보냈는데, 회사 컴퓨터엔 한컴오피스가 없다
- 아이폰으로 찍은 사진을 윈도우 PC로 옮겼더니 **.heic**라서 안 열린다
- 파일 변환 사이트에 회사 문서를 **업로드하기 찜찜하다**

이럴 때 쓰는 무료 프로그램을 소개합니다.

## 2. Filee가 뭔가요?

**Filee(파일리)**는 파일 형식을 바꿔주는 무료 프로그램이에요. 누구나 무료로 쓰고 고칠 수 있게 공개된 오픈소스이고, **한국 개발자(김명구 님)**가 만들었어요.

해외여행 갈 때 챙기는 **만능 어댑터** 아시죠? 콘센트 모양이 달라도 꽂기만 하면 충전되잖아요. Filee는 **파일용 만능 어댑터**예요.

- **268가지 형식**을 서로 바꿔줘요 (문서, 사진, 한글, 전자책, 압축 파일 등)
- **오피스나 한컴오피스를 따로 깔 필요가 없어요**
- **인터넷에 올리지 않고** 내 컴퓨터 안에서만 변환해요

10월 셋째 주에는 GitHub의 C# 프로그램 인기 순위에서 7일 연속 1위를 했고, 별(추천)을 1만 3천 개 넘게 받았어요.

## 3. 실제 화면으로 보기 — 끌어서 놓으면 끝

실제 프로그램 화면으로 세 가지 변환을 보여드릴게요.

[이미지: filee-demo.gif]

쓰는 법은 딱 이것뿐이에요.

1. 바꿀 파일을 **Ctrl 키를 누른 채** 끌기 시작하면
2. 커서 옆에 **동그란 메뉴**가 열려요
3. 원하는 형식 위에 **놓으면 끝**. 원본 옆에 새 파일이 생겨요

### ① 한글(HWP) → PDF
예시 회의록 HWP를 PDF 위에 놓으면 **1초쯤** 만에 PDF가 생겨요. 표와 제목 서식도 그대로예요.

[이미지: result-hwp-to-pdf.png]

**한글 2005로 만든 샘플 문서**로 테스트한 결과도 표, 그림, 각주까지 잘 나왔어요.

### ② 아이폰 사진(HEIC) → JPG
HEIC 사진을 JPG 위에 놓으면 바로 일반 사진 파일이 돼요. 여러 장을 한꺼번에 끌어도 돼요.

### ③ 도장 사진 → 배경 지우기
동그란 메뉴에서 **Tab 키**를 누르면 뒷면 메뉴가 나와요. 여기서 "배경 제거"에 놓으면, 흰 종이에 찍은 도장이 **배경이 투명한 그림**이 돼요. 전자 계약서나 견적서에 붙이기 좋아요.

[이미지: result-stamp.png]

## 4. 설치 방법 (Windows)

**방법 1. 직접 내려받기**
1. https://github.com/KnifeLemon/Filee/releases/latest 접속
2. `Filee-2.2.0-win-Setup.exe` 클릭해서 내려받기 → 실행
3. 설치 중 나오는 선택지는 기본값 그대로 두고 "다음"

**방법 2. Microsoft Store**
스토어에서 "Filee"를 검색해 설치해도 돼요.

처음 실행하면 "변환 엔진 선택" 창이 떠요. 동영상·음악 변환용 추가 프로그램이라, **문서·사진만 쓸 거라면 "나중에"**를 눌러도 돼요.

⚠️ **실행했는데 아무 창도 안 떠요!**
오래 업데이트하지 않은 Windows 10에서 생기는 문제래요. **Windows 업데이트**를 먼저 해주세요.

### 여러 파일을 한꺼번에 (조금 고급)
설치할 때 "filee 명령"을 켰다면, 명령 프롬프트(cmd)에서 이렇게 쓸 수 있어요.
```cmd
:: 폴더 안 아이폰 사진 전부 JPG로
filee convert C:\사진\*.heic --to jpg
```

## 5. 정리: 잘 되는 것, 안 되는 것

**👍 좋았던 점**
- 끌어서 놓기 한 번이라 **설명서가 필요 없어요**
- 업로드가 없어서 **회사 문서도 안심**
- 한글(HWP), 한글 자막 깨짐, 알집 압축처럼 **한국 사정을 잘 알아요**

**👎 아쉬운 점**
- **배경 제거는 흰 배경·단색 배경 전용**이에요. 고양이 사진, 커피잔 사진으로 테스트하면 사물까지 지워져요. 인물 사진 누끼는 다른 도구를 쓰세요.

[이미지: result-bg-fail.png]

- 동영상·음악 변환은 추가 엔진을 받아야 해요 (앱이 알아서 물어봐요)
- 맥(Mac) 버전은 아직 시험판이에요

## 6. 자주 묻는 질문

**Q. 정말 무료인가요?**
A. 네, 무료예요. 개발자는 후원을 받아 운영하고, 앞으로도 무료라고 밝히고 있어요.

**Q. 내 파일이 어디로 전송되진 않나요?**
A. 변환은 내 컴퓨터 안에서만 해요. 개발자도 파일을 올리지 않고 사용 기록도 보내지 않는다고 밝히고 있어요. (업데이트 확인, 추가 엔진 받기에만 인터넷을 써요.)

**Q. 한글 파일로도 만들 수 있나요?**
A. 네. 워드, PDF, 엑셀, 파워포인트를 HWPX(한글 최신 형식)로도 바꿀 수 있어요.

**Q. 회사 PC에 깔아도 되나요?**
A. 프로그램 자체는 MIT 라이선스라 회사에서도 무료로 쓸 수 있어요. 다만 회사 보안 정책상 설치 허가가 필요한지는 확인하세요.
