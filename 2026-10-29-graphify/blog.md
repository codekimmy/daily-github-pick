## 1. Graphify가 뭔가요?

프로그램은 보통 파일 수십~수백 개로 이루어져 있어요. 처음 보는 사람은 "어디서부터 읽어야 하지?"부터 막히죠.

**Graphify**는 이 파일들을 분석해서 **어떤 코드가 어떤 코드를 쓰는지 연결 관계를 지도로 그려주는 도구**예요. GitHub에서 별을 13만 개 넘게 받은, 요즘 가장 주목받는 오픈소스(누구나 무료로 쓰고 고칠 수 있게 공개된 프로그램) 중 하나입니다.

## 2. 지하철 노선도로 쉽게 이해하기

서울에 처음 온 친구에게 지하철역 300개 이름이 적힌 목록을 주면 어떨까요? 아무 도움이 안 되죠. 그런데 **노선도**를 주면 바로 길이 보여요.

Graphify가 하는 일이 정확히 그거예요.

- **역** = 코드 조각 (함수, 클래스 같은 프로그램의 부품)
- **노선** = "이 코드가 저 코드를 사용한다"는 연결
- **환승역** = 연결이 가장 많이 몰리는 핵심 코드

강남역, 신도림역만 알아도 서울 지하철이 반쯤 이해되잖아요? 프로그램도 **환승역 몇 개만 알면 전체 구조가 잡혀요.** Graphify는 이 환승역을 자동으로 찾아서 순위까지 매겨줍니다. (Graphify에서는 이걸 *God Node*라고 불러요.)

## 3. 직접 돌려봤습니다 — 파일 155개, 5초

파이썬에서 많이 쓰는 `click`이라는 프로그램(파일 155개)에 직접 돌려봤어요.

[이미지: terminal.gif]

| 항목 | 결과 |
|---|---|
| 걸린 시간 | **약 5초** |
| 찾아낸 코드 조각(점) | 3,460개 |
| 찾아낸 연결(선) | 6,725개 |
| AI 사용량 | **0** (돈 안 듦) |

그리고 환승역 순위는 이렇게 나왔어요.

1. `Context` — 연결 184개
2. `Command` — 연결 110개
3. `Parameter` — 연결 98개

`click`을 처음 공부하는 사람이라면 이 세 개부터 읽으면 된다는 뜻이에요. 문서를 한참 읽어야 알 수 있는 걸 5초 만에 알려준 셈이죠.

지도 화면은 이렇게 생겼어요. 색깔은 서로 가깝게 연결된 코드 묶음이에요.

[이미지: graph-view.png]

솔직히 큰 프로젝트는 지도만 보면 털뭉치 같아요. **진짜 유용한 건 함께 만들어지는 보고서 파일(GRAPH_REPORT.md)의 환승역 목록**이었어요.

### 놀랐던 점
- **AI를 안 쓴다**: 코드 분석은 내 컴퓨터 안에서 규칙대로 처리해요. 그래서 무료이고, 회사 코드가 밖으로 나갈 걱정도 없어요.
- **믿을 수 있는 정도를 알려준다**: 연결마다 "코드에 직접 써 있음"인지 "추론함"인지 표시해요. 이번 결과는 77%가 직접 확인된 연결이었어요.

## 4. 설치 방법 (Windows)

명령 프롬프트(cmd)를 열고 순서대로 입력하세요.

```cmd
:: uv 설치 (파이썬 도구 설치기, 처음 한 번만)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

:: Graphify 설치 — 이름 끝에 y가 두 개예요!
uv tool install graphifyy

:: 분석할 폴더로 이동
cd C:\내프로젝트

:: 지도 만들기
graphify update .

:: 결과 열기
start graphify-out\graph.html
```

⚠️ **자주 하는 실수**
- `graphifyy`(y 두 개)가 공식이에요. y 하나짜리는 다른 패키지예요.
- `graphify`를 못 찾는다고 나오면 `uv tool update-shell` 입력 후 cmd 창을 새로 여세요.

궁금한 코드가 있으면 이렇게 물어볼 수도 있어요.
```cmd
:: 이 코드가 뭐랑 연결돼 있나
graphify explain "함수이름"

:: 두 코드가 어떻게 이어지나
graphify path "A" "B"
```

## 5. 어디에 쓰면 좋을까

- **새 프로젝트에 투입된 개발자** — 어디부터 읽을지 바로 파악
- **AI로 코딩하는 분** — AI가 만든 코드가 어떻게 엮였는지 눈으로 확인. Claude Code, Cursor 같은 AI 도구에 연결하면 AI가 파일을 뒤지기 전에 지도부터 보게 돼서 사용량도 아낄 수 있어요.
- **개발 공부하는 학생** — 유명 오픈소스의 뼈대를 지도로 공부
- **기획자·PM** — 개발팀과 구조를 같이 보며 대화

## 6. 자주 묻는 질문

**Q. 돈이 드나요?**
A. 코드 분석은 무료예요. 문서·PDF·영상까지 분석할 때만 AI가 쓰여서 비용이 생길 수 있어요.

**Q. 코딩을 못해도 쓸 수 있나요?**
A. 설치와 실행은 위 명령어 복붙이면 돼요. 다만 결과를 해석하려면 기초 지식이 조금 있으면 좋아요.

**Q. 어떤 언어를 지원하나요?**
A. 파이썬, 자바스크립트, 타입스크립트 등 주요 언어를 지원해요. 코드 구조를 읽는 tree-sitter라는 분석기를 써요.

**Q. 지도가 너무 복잡해요.**
A. 테스트 코드까지 다 들어가서 그래요. 본 코드 폴더(예: `src`)만 지정해서 돌리면 훨씬 깔끔해요.
