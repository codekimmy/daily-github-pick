## 1. auto-editor가 뭔가요?

**auto-editor(오토 에디터)**는 영상에서 **말 없는 부분을 자동으로 잘라 주는** 무료 프로그램이에요. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**이고, 미국 개발자가 만들었어요.

영상을 찍다 보면 "음…", "어, 잠시만요" 뒤에 빈 시간이 꼭 생기죠. 편집 프로그램에서 이걸 하나하나 자르는 게 제일 지루한 일이에요. CapCut Pro 같은 유료 도구에는 이걸 해 주는 기능이 있는데, auto-editor는 **무료로, 내 컴퓨터 안에서** 해 줘요.

## 2. 비유로 쉽게 이해하기

auto-editor는 **자동 가위**예요.

1. 영상의 소리 크기를 한 칸씩 재요
2. 조용한 칸만 골라 가위로 오려 내요
3. 남은 칸을 이어 붙여요

가위질 정도도 바꿀 수 있어요. 말 앞뒤를 조금 남겨 두거나, 오려 내는 대신 빨리 감을 수도 있어요.

## 3. 실제 화면으로 보기

직접 만든 **58초짜리 가상 강의 영상**(라면 끓이는 법)으로 테스트했어요. 말하다가 2~5초씩 멈추는 장면이 들어 있어요.

[이미지: auto-editor-anim.gif]

파란 곳은 말하는 곳, 빨간 곳은 조용한 곳이에요. 명령 한 줄을 넣으면 빨간 곳이 잘려 나가요.

[이미지: terminal.gif]

| 방법 | 결과 길이 |
|---|---|
| 원본 | 57.9초 |
| 기본 자르기 | **29.0초 (−50%)** |
| 말 앞뒤 여유 0.5초 | 35.0초 |
| 자르지 않고 조용한 곳만 4배속 | 36.2초 |

자르는 데 걸린 시간은 **약 6초**예요. 원본 파일은 그대로 두고, 이름 뒤에 `_ALTERED`가 붙은 새 파일이 생겨요.

### 편집 프로그램으로 넘기기
잘린 영상 대신 **편집 파일**로 받을 수도 있어요. 프리미어 프로, 다빈치 리졸브, 파이널 컷 프로, 샷컷, 케이든라이브용 파일이 모두 만들어졌어요. 편집 프로그램에서 불러오기만 하면, 잘린 상태 그대로 편집을 이어 갈 수 있는 방식이에요. (편집 프로그램에서 직접 열어 보는 것까지는 테스트하지 못했어요.)

## 4. 설치 방법 (Windows)

**1) 파이썬 설치**
https://python.org 에서 파이썬을 받아 설치해요. 첫 화면 아래 **"Add python.exe to PATH"를 꼭 체크**하세요.

**2) 명령 프롬프트(cmd)에 한 줄씩 붙여넣기**
```cmd
:: auto-editor 설치
pip install auto-editor
:: 처음 한 번: 실제 편집 프로그램 파일(약 40MB) 자동 다운로드
auto-editor --version
:: 영상이 있는 폴더로 이동
cd %USERPROFILE%\Videos
:: 얼마나 잘릴지 미리보기
auto-editor 강의.mp4 --preview
:: 진짜 자르기
auto-editor 강의.mp4
```

**자주 쓰는 옵션**
```cmd
:: 말 앞뒤 0.5초 여유 (덜 딱딱하게)
auto-editor 강의.mp4 -m 0.5s
:: 자르지 말고 조용한 곳만 4배속
auto-editor 강의.mp4 --when-silent speed:4
:: 프리미어용 편집 파일 만들기
auto-editor 강의.mp4 --export premiere
```

## 5. 어디에 쓰면 좋을까

- **유튜버·브이로거** → 말 없는 구간 초벌 컷
- **선생님·강사** → 수업 녹화를 짧게 줄여 올리기
- **직장인** → 1시간 회의 녹화를 몰아보기

**👎 아쉬운 점**
- **배경음악이 깔린 영상은 거의 안 잘려요.** 음악을 넣기 전 원본에 쓰세요
- **말 없이 화면만 보여 주는 장면도 잘려요.** 이럴 땐 빨리 감기 옵션을 쓰세요
- 버튼 누르는 화면이 없는 **명령어 방식**이에요
- 처음 실행할 때 인터넷으로 실제 편집 프로그램 파일을 받아야 해요

## 6. 자주 묻는 질문

**Q. 정말 무료인가요?**
A. 네. 저작권을 포기한 완전 무료 공개(Unlicense)라 회사에서도 자유롭게 쓸 수 있어요.

**Q. 영상이 어딘가로 올라가나요?**
A. 아니요. 내 컴퓨터 안에서만 처리해요. 인터넷은 처음 실행할 때 실제 편집 프로그램 파일을 받는 데만 써요.

**Q. 말 끝이 잘려요.**
A. `-m 0.5s`처럼 여유를 늘려 보세요. 테스트에서는 0.5초가 가장 자연스러웠어요.

**Q. 에어컨 소리 같은 잡음이 있으면요?**
A. `--edit audio:threshold=0.08`처럼 숫자를 올리면 작은 소리를 "조용함"으로 봐요. 기본값은 0.04예요.

## 마무리

컷 편집에서 가장 지루한 "빈 시간 자르기"를 **명령 한 줄**로 끝낼 수 있어요. 완벽한 편집은 아니지만, 초벌 컷을 맡기고 마무리만 직접 하면 편집 시간이 확 줄어요.
