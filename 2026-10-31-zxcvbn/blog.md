# 내 비밀번호 몇 초면 뚫릴까? 무료 비밀번호 강도 계산기 zxcvbn 사용법 총정리

## 1. zxcvbn이 뭔가요?

**zxcvbn**은 비밀번호가 **얼마나 빨리 뚫릴지 계산해 주는** 무료 프로그램이에요. 클라우드 저장소 회사 **Dropbox**가 만들어 누구나 무료로 쓰고 고칠 수 있게 공개한 **오픈소스**예요.

원래는 개발자가 **회원가입 화면에 넣는 부품**이에요. 비밀번호를 칠 때 "약함 / 보통 / 강함" 막대가 움직이는 화면, 본 적 있으시죠? 그런 화면 뒤에서 계산을 맡는 역할이에요.

이 글에서는 일반인도 바로 쓸 수 있게 **한국어 계산기 파일**을 함께 만들어 두었어요. 더블클릭만 하면 돼요.

## 2. 비유로 쉽게 이해하기

zxcvbn은 **자물쇠 따는 시간을 재는 초시계**예요.

도둑은 열쇠를 아무렇게나 넣지 않아요. 이런 순서로 넣어 봐요.

1. 가장 흔한 비밀번호 목록 (123456, password …)
2. 영어 단어·이름 (tiger, minsu …)
3. 키보드 줄·날짜 (qwer, 1995 …)
4. 그래도 안 되면 하나씩 전부

zxcvbn은 이 순서를 흉내 내서 **"몇 번째 열쇠에서 열릴까?"**를 세고, 그걸 시간으로 바꿔 보여 줘요. 이름도 키보드 맨 아랫줄 **z x c v b n**에서 따왔어요.

## 3. 실제 화면으로 보기

시연용 예시 비밀번호 12개로 테스트했어요. 시간은 **"사이트에서 훔친 비밀번호 파일을 1초에 1만 번씩 맞혀 볼 때"** 기준이에요.

[이미지: zxcvbn-anim.gif]

| 비밀번호 | 뚫리는 시간 |
|---|---|
| 123456 | 1초도 안 걸림 |
| password1 | 1초도 안 걸림 |
| P@ssw0rd | 1초도 안 걸림 |
| qwer1234! | 약 1초 |
| minsu1995 (이름 + 태어난 해) | 약 17분 |
| Summer2026! | 약 46분 |
| X9#qLm2$vR8! (무작위 12자리) | 약 3년 |
| tiger-gimbap-umbrella (단어 3개) | **100년 넘게** |

계산은 비밀번호 1개에 **1천분의 1초 안팎**이면 끝나요. 눈 깜빡하는 시간보다 훨씬 빨라요.

### 놀라운 점 ① 기호로 바꿔도 소용없어요
`password`의 a를 @로, o를 0으로 바꾼 `P@ssw0rd`도 **1초도 안 걸려요.** 도둑도 이 수법을 알고 있어서 먼저 넣어 보거든요.

[이미지: page-mid.png]

### 놀라운 점 ② 이름을 알면 확 약해져요
`minsu1995`는 약 17분이에요. 그런데 아래 칸에 **"내 이름은 minsu"라고 알려 주면 약 2초**로 줄어요. SNS에 이름과 생일이 있다면, 도둑도 이걸 먼저 넣어 봐요.

[이미지: page-name.png]

### 놀라운 점 ③ 단어를 이어 쓰면 확 세져요
`tiger`(1초도 안) → `tiger-gimbap`(약 5일) → `tiger-gimbap-umbrella`(100년 넘게). **기호 하나보다 관련 없는 단어 하나를 더 붙이는 게** 훨씬 세요.

## 4. 사용 방법 (Windows)

**방법 1 — 설치 없이 (추천)**
1. 아래 저장소 폴더에서 `password-check.html` 파일을 받아요
2. 더블클릭하면 크롬·엣지에서 열려요
3. 비밀번호 칸에 입력하면 바로 결과가 나와요

인터넷을 끊은 상태에서 열어 테스트했는데 **바깥으로 나가는 요청이 0건**이었어요. 입력한 비밀번호는 어디에도 보내지 않아요.

**방법 2 — 파이썬으로**
https://python.org 에서 파이썬을 설치해요. 첫 화면 아래 **"Add python.exe to PATH"를 꼭 체크**하세요. 그다음 명령 프롬프트(cmd)에 붙여넣어요.

```cmd
:: zxcvbn 설치
pip install zxcvbn
:: 저장소에서 받은 demo 폴더로 이동
cd %USERPROFILE%\Downloads\demo
:: 비밀번호 확인 (입력해도 화면에 안 보임)
python check_password.py
```

[이미지: terminal.gif]

> 💡 파이썬판에 원래 들어 있는 `zxcvbn` 명령은 입력을 기다리는 방식 때문에 Windows에서 막힐 수 있어요. 그래서 Windows에서도 되는 `check_password.py`를 따로 만들어 두었어요.

## 5. 어디에 쓰면 좋을까

- **새 비밀번호를 만들 때** → 만들기 전에 몇 년 버틸지 미리 재 보기
- **부모님 계정 챙길 때** → 가족 비밀번호가 흔한 목록에 있는지 확인
- **보안 교육** → "기호보다 길이"를 숫자로 보여 주기

**👎 아쉬운 점**
- **한국어를 몰라요.** '안녕하세요'를 영어 자판으로 친 `dkssudgktpdy`를 "매우 안전, 약 3년"으로 봤어요. 한국에서 흔한 수법이라 실제로는 더 약할 수 있어요
- **이미 유출된 비밀번호인지는 알려 주지 않아요**
- 원본은 **2017년 이후 새 버전이 없어요** (파이썬판은 4.5.0)
- 시간은 **어림값**이에요. "어느 쪽이 훨씬 센지" 비교하는 용도로 쓰세요

## 6. 자주 묻는 질문

**Q. 진짜 비밀번호를 넣어도 되나요?**
A. 계산기 파일은 인터넷 없이 내 컴퓨터 안에서만 계산해요. 다만 공용 PC에서는 넣지 마세요.

**Q. 정말 무료인가요?**
A. 네. MIT 라이선스라 개인도 회사도 무료로 쓸 수 있어요.

**Q. 기호·숫자·대문자는 꼭 넣어야 하나요?**
A. zxcvbn 기준으로는 꼭 필요하진 않아요. 관련 없는 단어 3~4개를 이어 쓰는 게 더 효과가 컸어요. 사이트 규칙이 기호를 요구하면 그때 붙이면 돼요.

**Q. "1초에 1만 번"은 무슨 뜻이에요?**
A. 사이트에서 비밀번호 파일을 훔쳐 간 도둑이, 잘 보호된 파일을 푸는 속도를 가정한 거예요. 허술하게 보호된 사이트라면 1초에 100억 번까지 가정해요. 계산기 화면에 세 가지 속도가 모두 나와요.

## 마무리

규칙을 다 지킨 `P@ssw0rd`도 1초, 단어 세 개를 이은 비밀번호는 100년. **비밀번호는 복잡함보다 길이**라는 걸 숫자로 확인할 수 있는 도구예요. 다음 비밀번호를 바꿀 때 한 번 재 보세요.
