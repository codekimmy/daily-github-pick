# 사진 배경 1초 만에 지우기, 무료 누끼 프로그램 rembg 사용법 총정리

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 사진을 넣으면 주인공만 남기고 배경을 투명하게 지워 주는 무료 프로그램이에요.
> ⭐ 별 약 2.5만 · 무료 오픈소스 · MIT 라이선스 · 파이썬

> **일반인 쓸모 ★★★★☆** — 파이썬을 깔고 명령 한 줄이면 쓸 수 있어요. 명령어가 낯설면 사진을 끌어다 놓기만 하는 파일도 준비해 두었어요.
> **이걸로 할 수 있는 것**
> 1. 중고거래에 올릴 물건 사진의 **지저분한 배경을 지우고 흰 배경**으로 바꾼다
> 2. 반려동물·커피·소품 사진에서 **주인공만 오려** 카드·썸네일·스티커에 붙인다
> 3. 쇼핑몰 상품 사진 수십 장을 **폴더째 넣어 한 번에** 배경을 지운다

## 1. rembg가 뭔가요?

**rembg**는 사진의 **배경을 자동으로 지워 주는** 무료 프로그램이에요. 이름도 remove background(배경 지우기)를 줄인 말이에요. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**예요.

디자이너들이 "누끼 딴다"고 부르는 작업 있죠? 사진에서 주인공만 남기고 나머지를 지우는 일이요. 포토샵으로 하면 한참 걸리는 이 일을 **명령 한 줄**로 해 줘요.

사진은 **내 컴퓨터 안에서만** 처리해요. 인터넷 사이트에 사진을 올릴 필요가 없어요.

## 2. 비유로 쉽게 이해하기

rembg는 **주인공만 오려 내는 자동 가위**예요.

잡지에서 사진을 오릴 때처럼, 이런 순서로 움직여요.

1. 사진을 보고 **어디가 주인공인지** 찾아요
2. 주인공 모양대로 **흑백 본**을 그려요 (흰색 = 남길 곳, 검은색 = 지울 곳. 이걸 '마스크'라고 불러요)
3. 본 바깥을 **투명하게** 오려 내요

가위 날에 해당하는 게 **모델**(미리 학습해 둔 AI 파일)이에요. 날마다 크기와 꼼꼼함이 달라서, 같은 사진도 모델에 따라 오리는 모양이 조금씩 달라요.

## 3. 실제 화면으로 보기

저작권 없는 공개 사진 3장(커피잔·고양이·로켓)으로 테스트했어요. 그래픽카드 없는 보통 컴퓨터 성능(CPU 2개) 기준이에요.

[이미지: rembg-anim.gif]

[이미지: before-after.png]

| 사진 | 걸린 시간 (기본 추천 모델) | 결과 |
|---|---|---|
| 커피잔 | 1.2초 | 숟가락 손잡이까지 깔끔 |
| 고양이 | 1.1초 | 얼굴은 깔끔, 가는 수염은 흐릿 |
| 로켓 | 1.1초 | 로켓만 남기고 발사대는 지움 |

사진 한 장에 **1초 안팎**이에요. 라면 물 올리기도 전에 끝나요.

### 놀라운 점 ① 흰 배경도 한 번에
투명 대신 **흰 배경**으로 바로 저장할 수도 있어요. 중고거래 사진을 올릴 때 딱이에요. 투명 PNG를 다른 그림 위에 얹으면 새 배경도 만들 수 있어요.

### 놀라운 점 ② 모델마다 '주인공'이 달라요
같은 로켓 사진을 모델 4개로 오리면 결과가 달라요. 세 모델은 **로켓만** 남겼는데, 꼼꼼한 모델은 **발사대 탑까지** 남겼어요. 결과가 마음에 안 들면 모델만 바꿔 보면 돼요.

[이미지: models-rocket.png]

| 모델 | 크기 | 걸린 시간 |
|---|---|---|
| u2netp (가벼운) | 5MB | 0.6초 |
| silueta (중간) | 44MB | 1.6초 |
| **u2net (기본 추천)** | 176MB | 1.1초 |
| isnet-general-use (꼼꼼한) | 179MB | 3.0초 |

### 놀라운 점 ③ 고양이 수염은 아직 어려워요
얼굴은 잘 오렸지만 **가는 수염은 회색 줄처럼 흐릿하게** 남았어요. 테두리 다듬기 옵션(`-a`)을 켜면 경계는 부드러워지지만, 이 사진에선 **수염이 오히려 거의 사라졌어요.** 털이 많은 사진은 확대해서 꼭 확인하세요.

## 4. 사용 방법 (Windows)

**준비 (처음 한 번)**
https://python.org 에서 파이썬(3.11 이상)을 설치해요. 첫 화면 아래 **"Add python.exe to PATH"를 꼭 체크**하세요. 그다음 명령 프롬프트(cmd)에 붙여넣어요.

```cmd
:: rembg 설치 ([cpu,cli]를 꼭 붙이기)
pip install "rembg[cpu,cli]"
```

**사진 한 장**
```cmd
:: 사진이 있는 폴더로 이동
cd %USERPROFILE%\Downloads
:: 배경을 투명하게 (-m u2net = 모델 이름, 꼭 적기)
rembg i -m u2net coffee.jpg coffee_nobg.png
:: 흰 배경으로
rembg i -m u2net -bgc 255 255 255 255 coffee.jpg coffee_white.png
```

**폴더째 한 번에**
```cmd
:: input 폴더의 사진 전부 → output 폴더로
rembg p -m u2net input output
```

[이미지: terminal.gif]

처음 실행할 때만 모델 파일(176MB)을 받아요. 그다음부터는 인터넷 없이 돼요.

> 💡 **명령어가 어렵다면** — 아래 저장소 폴더의 `drag_remove_bg.bat` 파일을 바탕화면에 두고, 사진을 그 위에 끌어다 놓으세요. 사진 옆에 투명 배경·흰 배경 파일이 생겨요.

> ⚠️ **모델 이름(`-m u2net`)을 꼭 적으세요.** 안 적으면 1GB짜리 기본 모델을 받는데, 메모리 8GB 컴퓨터 테스트에서는 두 번 모두 강제 종료됐어요.

## 5. 어디에 쓰면 좋을까

- **중고거래·쇼핑몰** → 물건 사진 배경을 흰색으로 통일
- **카드뉴스·썸네일** → 주인공만 오려 다른 배경에 얹기
- **반려동물 사진** → 우리 집 고양이 스티커 만들기

**👎 아쉬운 점**
- **모델 이름을 안 적으면** 큰 기본 모델 때문에 멈출 수 있어요
- **가는 수염·머리카락·연기**처럼 흐릿한 경계는 깔끔하지 않아요
- 결과 파일 이름을 `.jpg`로 지어도 **속은 PNG**예요. `.png`로 저장하세요
- 창이 있는 프로그램이 아니라 **명령 프롬프트**로 써야 해요 (끌어다 놓기 파일로 보완)

## 6. 자주 묻는 질문

**Q. 정말 무료인가요?**
A. 네. MIT 라이선스라 개인도 회사도 무료로 쓸 수 있어요.

**Q. 사진이 인터넷으로 나가나요?**
A. 아니요. 처음에 모델 파일만 받고, 사진은 내 컴퓨터 안에서만 처리해요.

**Q. 그래픽카드가 없어도 되나요?**
A. 네. 테스트도 그래픽카드 없이 CPU만으로 했고, 사진 한 장에 1초 안팎이었어요.

**Q. 사람 사진도 되나요?**
A. 사람 전용 모델(`u2net_human_seg`)도 들어 있어요. 이번 테스트에서는 사람 사진을 쓰지 않아서 결과는 확인하지 못했어요.
