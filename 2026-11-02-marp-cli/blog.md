# 메모장 글을 발표 자료로 2초, 무료 PPT 만들기 프로그램 marp-cli 사용법 총정리

## 1. marp-cli가 뭔가요?

**marp-cli**(마프 씨엘아이)는 **메모장에 쓴 글을 발표 슬라이드로 바꿔 주는** 무료 프로그램이에요. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**이고, 일본의 marp-team이 만들었어요.

발표 자료를 만들 때 내용보다 **글자 크기 맞추고 상자 옮기는 데** 시간이 더 걸린 적 있죠? marp-cli는 그 일을 대신해 줘요. 나는 글만 쓰고, 꾸미기는 프로그램이 해요.

이름 끝의 CLI는 '명령어로 쓰는 프로그램'이라는 뜻이에요. 창이 뜨는 프로그램이 아니라 **명령 프롬프트에 한 줄**을 넣어서 써요.

## 2. 비유로 쉽게 이해하기

marp-cli는 **원고만 넘기면 슬라이드를 찍어 주는 '발표 자료 인쇄소'**예요.

인쇄소에 맡길 때처럼 세 가지만 정하면 돼요.

1. **원고** — 메모장에 쓴 글. `#`은 제목, `-`는 목록, `---` 한 줄은 "여기서 다음 장"이라는 표시예요 (이런 간단한 글 규칙을 '마크다운'이라고 불러요)
2. **디자인 틀** — 테마. 기본·따뜻한 색·가운데 정렬 3가지가 들어 있어요
3. **인쇄 방식** — PDF, 파워포인트, 그림(PNG), 웹페이지(HTML) 중에서 골라요

글자 크기와 위치는 인쇄소가 맞춰요. 내용을 고치고 싶으면 원고만 고쳐서 다시 찍으면 돼요.

## 3. 실제 화면으로 보기

시연용으로 만든 가상 원고(제주도 가족 여행 계획, 메모장 31줄)로 실행한 결과예요. 그래픽카드 없는 보통 컴퓨터 성능(CPU 2개) 기준이에요.

[이미지: marp-anim.gif]

| 만든 것 | 걸린 시간 | 결과 |
|---|---|---|
| PDF | **2.0초** | 4쪽, 한글·표·굵은 글씨 그대로 |
| 파워포인트 | **2.2초** | 4장 (장마다 그림 1장) |
| 그림(PNG) | 2.1초 | 장마다 그림 파일 4개 |
| 웹페이지 | **0.5초** | 브라우저로 열어 발표 |

메모장 글 31줄이 **2초 만에** 발표 자료가 됐어요. 전자레인지 버튼 누르는 시간보다 짧아요.

### 놀라운 점 ① 한 단어로 디자인이 바뀌어요
원고 맨 위 `theme: default`를 `gaia`나 `uncover`로 바꾸기만 하면 바탕색·글자 배치가 통째로 바뀌어요. 아래 세 장은 글을 한 글자도 안 고치고 테마만 바꾼 결과예요.

[이미지: themes.png]

### 놀라운 점 ② 20장도 거의 같은 시간
**20장짜리 원고**로 실행한 결과, PDF는 **2.2초**로 4장일 때(2.0초)와 거의 같았어요. 시간 대부분이 프로그램을 켜는 시간이라서예요.

### 놀라운 점 ③ 저장하면 알아서 다시 만들어요
`-w`를 붙여 실행해 둔 상태에서 원고에 "4. 우산" 한 줄을 넣어 저장하자, **몇 초 안에 PDF에도 우산이 생겼어요** (시연 결과). 원고를 고치면서 결과를 바로 볼 수 있어요.

## 4. 사용 방법 (Windows)

**준비 (처음 한 번)**
https://nodejs.org 에서 **LTS** 버전을 받아 설치해요. 그다음 명령 프롬프트(cmd)를 새로 열고 붙여넣어요.

```cmd
:: marp-cli 설치
npm install -g @marp-team/marp-cli
:: 설치 확인 (버전 번호가 나오면 성공)
marp --version
```

**원고 쓰기**
메모장에 아래처럼 쓰고 `trip.md`로 저장해요 (파일 형식 '모든 파일', 인코딩 'UTF-8').

```markdown
---
marp: true
theme: default
paginate: true
---

# 제주도 가족 여행 계획
2026년 11월 · 2박 3일

---

## 준비물
1. 신분증
2. 충전기
```

**발표 자료 만들기**
```cmd
:: 원고가 있는 폴더로 이동
cd %USERPROFILE%\Documents
:: PDF로
marp trip.md -o trip.pdf
:: 파워포인트로
marp trip.md --pptx -o trip.pptx
:: 장마다 그림으로
marp trip.md --images png
```

[이미지: terminal.gif]

> 💡 **명령어가 어렵다면** — 아래 저장소 폴더의 `drag_to_slides.bat` 파일을 바탕화면에 두고, `.md` 원고를 그 위에 끌어다 놓으세요. 원고 옆에 PDF와 PPTX가 생겨요.

> ⚠️ **파워포인트 파일은 장마다 '그림 한 장'이에요.** 파워포인트에서 글자를 고칠 수 없어요. 고칠 일이 있으면 원고를 고쳐 다시 만드세요.

## 5. 어디에 쓰면 좋을까

- **회의·보고가 잦은 직장인** → 메모로 정리한 안건을 바로 PDF 발표 자료로
- **학생** → 조별 발표 초안을 글로 쓰고 슬라이드로 뽑기
- **카드뉴스·SNS** → 장마다 그림(PNG)으로 뽑아 바로 올리기

**👎 아쉬운 점**
- **기본 파워포인트 파일은 글자를 고칠 수 없어요** (장마다 그림)
- 글자를 고칠 수 있게 만드는 옵션(`--pptx-editable`)은 **LibreOffice가 있어야** 하고, 시연에서는 굵은 글씨가 빠지고 숫자 줄이 어긋났어요

[이미지: pptx-editable.png]

- 자동 실행 환경에서는 `--no-stdin` 없이 실행하면 **20초 넘게 기다리기만** 했어요. 반응이 없으면 이 옵션을 붙여 보세요
- `#`, `-`, `---` 같은 **기호를 조금 익혀야** 해요
- 화려한 애니메이션·도형 편집 기능은 없어요. 글·표 중심 자료에 알맞아요

## 6. 자주 묻는 질문

**Q. 정말 무료인가요?**
A. 네. MIT 라이선스라 개인도 회사도 무료로 쓸 수 있어요.

**Q. 파워포인트가 없어도 되나요?**
A. 네. PDF·그림·웹페이지는 파워포인트 없이 만들어지고, PPTX 파일도 marp-cli가 직접 만들어요. 다만 PDF·PPTX를 만들 때 크롬이나 엣지 같은 브라우저를 빌려 써요 (윈도우에는 엣지가 기본으로 들어 있어요).

**Q. 한글이 깨지지 않나요?**
A. 시연에서는 한글·표·굵은 글씨 모두 그대로 나왔어요. 원고를 저장할 때 인코딩을 **UTF-8**로 고르세요.

**Q. 사진도 넣을 수 있나요?**
A. 원고에 `![](사진.jpg)`처럼 쓰면 돼요. 내 컴퓨터 사진이 PDF에 안 나오면 명령에 `--allow-local-files`를 붙이라고 공식 문서에 적혀 있어요. 이번 시연 원고에는 사진을 넣지 않았어요.
