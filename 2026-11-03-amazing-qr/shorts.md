**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
이 그림이 QR코드라고? 0.13초 #shorts
```

**설명란**
```
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

내 그림을 배경으로 QR코드를 만들어 주는 무료 프로그램 amazing-qr!
그림 한 장 + 명령 한 줄이면 0.13초. 움직이는 QR, 와이파이 QR도 됩니다. 사용법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 그림 QR은 휴대폰마다 안 읽힐 수 있습니다. 인쇄 전에 여러 휴대폰으로 꼭 찍어 확인하시기 바랍니다.

#QR코드 #QR코드만들기 #꿀팁 #가게홍보 #디자인 #오픈소스 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
파이썬 설치 후 cmd에서 pip install amzqr, 사용은 amzqr 주소 -p 그림.jpg -c 입니다. GIF를 넣으면 움직이는 QR이 되고, 한글 글자는 넣을 수 없습니다! 끌어다 놓기 파일과 명령어 모음은 전체 영상 설명란 링크에 있습니다.
```
