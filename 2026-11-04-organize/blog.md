# 다운로드 폴더 자동 정리, 무료 프로그램 organize 사용법 총정리 (영수증 PDF·중복 사진까지)

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 규칙을 한 번 써 두면, 명령 한 줄로 폴더 속 파일을 규칙대로 옮겨 주는 무료 프로그램입니다.
> ⭐ 별 약 3,200 · 무료 오픈소스 · MIT 라이선스 · 파이썬

> **일반인 쓸모 ★★★★☆** — 파이썬을 깔고 명령 한 줄이면 쓸 수 있습니다. 규칙 파일과 끌어다 놓기 파일을 준비해 두어서 규칙을 새로 쓰지 않아도 됩니다. 규칙을 바꾸려면 글로 고쳐야 하고 되돌리기 버튼이 없어서 별 하나를 뺐습니다.
> **이걸로 할 수 있는 것**
> 1. **다운로드 폴더**의 사진·문서·영상·설치 파일을 **종류별 폴더로 한 번에** 나눈다
> 2. 이름이 엉뚱해도 **PDF 속에 '영수증' 글자가 있으면 영수증/연도 폴더로** 모은다
> 3. `(1)`, `- 복사본`처럼 **내용이 똑같은 중복 파일**을 따로 골라낸다

## 1. organize란 무엇입니까?

**organize**(오거나이즈)는 **정해 둔 규칙대로 파일을 폴더별로 옮겨 주는** 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**이고, 독일 개발자가 2017년부터 만들어 GitHub에서 별 3천 개 넘게 받았습니다.

다운로드 폴더는 금방 `download (3).pdf`, `IMG_2034 (1).jpg`, `KakaoTalk_Setup.exe`로 뒤죽박죽이 됩니다. 손으로 하나씩 옮기는 대신 **"사진은 사진 폴더로, 영수증은 영수증 폴더로"** 같은 규칙을 한 번 적어 두면, 그다음부터는 명령 한 줄로 끝납니다.

창이 뜨는 프로그램이 아니라 **명령 프롬프트에 한 줄**을 넣어서 씁니다. 설치 이름은 `organize-tool`, 명령 이름은 `organize`입니다.

## 2. 비유로 쉽게 이해하기

organize는 **규칙표를 보고 편지를 칸마다 넣는 '우체국 분류원'**입니다.

1. **편지** — 정리할 파일
2. **칸** — 폴더 (`사진/`, `문서/`, `영수증/2026/` …). 칸이 없으면 새로 만듭니다
3. **규칙표** — 설정 파일 `config.yaml`. "어디서 · 무엇을 · 어떻게"를 적습니다

분류원은 규칙표를 **위에서부터 차례로** 봅니다. 그리고 일하는 방법이 두 가지입니다.

- `organize sim` — 편지에 **"여기로 갈 예정" 쪽지만** 붙이는 미리보기 (파일은 그대로)
- `organize run` — **실제로 칸에 넣는** 정리

## 3. 실제 화면으로 보기

시연용으로 만든 가상 파일 27개(가상 영수증 PDF, 사진과 복사본, 워드·엑셀 문서, 가짜 영상·설치 파일 등)로 클라우드에서 자동으로 실행한 결과입니다. 그래픽카드 없는 보통 컴퓨터 성능(CPU 2개) 기준이고, 규칙은 7개를 썼습니다.

[이미지: organize-anim.gif]

| 해 본 것 | 걸린 시간 | 결과 |
|---|---|---|
| 미리보기 (sim) | 0.39초 | 파일 27개 **그대로** |
| 실제 정리 (run) | **0.39초** | **26개 이동**, 폴더 7개 생김 |
| 한 번 더 실행 | 0.35초 | 이동 **0개** |
| 가짜 파일 1,000개 | **1.58초** | 875개 이동 |

파일 27개 정리가 **눈 깜빡할 시간(0.39초)**에 끝났습니다. 남은 1개는 받은 지 30일이 안 된 설치 파일이라 '오래된 설치 파일' 규칙에 걸리지 않은 것입니다.

[이미지: before-after.png]

### 놀라운 점 ① 이름이 아니라 내용으로 영수증을 찾습니다
`scan_0412.pdf`, `download (3).pdf`, `KakaoTalk_file_0901.pdf` — 이름만 봐서는 무엇인지 모르는 PDF 3개가, **PDF 속 '영수증' 글자**를 보고 `영수증/2025`, `영수증/2026` 폴더로 들어갔습니다.

### 놀라운 점 ② 중복은 '내용'으로 가립니다
`IMG_2034 (1).jpg`, `KakaoTalk_Photo_01 - 복사본.jpg`는 원본과 내용이 똑같아서 `중복/` 폴더로 갔습니다. 반면 `자기소개서_최종_진짜최종.docx`는 이름이 비슷해도 **내용이 달라서** 중복이 아닌 문서로 남았습니다.

### 꼭 알아 둘 점 — 되돌리기가 없습니다
`run`은 파일을 **실제로 옮깁니다.** 되돌리기 버튼이 없으니 **처음에는 반드시 `sim`으로 미리보기**를 하시기 바랍니다. 또 시연에서 이런 한계가 있었습니다.

- 새로 받은 사진이 이미 `사진/` 폴더에 있는 사진의 복사본이어도 **중복으로 잡히지 않았습니다** (중복 찾기는 같은 폴더 안 파일끼리만 비교)
- 글자 없이 그림으로만 된 **스캔 PDF는 영수증으로 못 찾았습니다**
- 같은 이름 파일이 이미 있으면 덮어쓰지 않고 `메모 2.txt`처럼 **이름을 바꿔** 넣었습니다

## 4. 사용 방법 (Windows)

**준비 (처음 한 번)**
https://www.python.org/downloads/ 에서 파이썬을 받아 설치합니다. 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다. 그다음 명령 프롬프트(cmd)를 새로 열고 붙여넣습니다.

```cmd
:: organize 설치 (설치 이름 organize-tool, 명령 이름 organize)
pip install organize-tool
:: 설치 확인 (organize v3.3.0 처럼 나오면 성공)
organize --version
```

그리고 아래 저장소 폴더의 **규칙 파일 `config.yaml`**을 받아 `C:\정리` 폴더에 둡니다.

**정리하기 — 꼭 미리보기부터**
```cmd
:: 규칙 파일이 있는 폴더로 이동
cd /d C:\정리
:: 1) 미리보기: 어디로 갈지 보기만 (파일은 그대로)
organize sim config.yaml -W "%USERPROFILE%\Downloads"
:: 2) 실제 정리: 파일이 진짜로 옮겨짐
organize run config.yaml -W "%USERPROFILE%\Downloads"
```

[이미지: terminal.gif]

> 💡 **명령어가 어렵다면** — 저장소 폴더의 `organize_folder.bat`와 `config.yaml`을 같은 폴더에 두고, 정리할 폴더를 `.bat` 아이콘 위로 끌어다 놓으시기 바랍니다. 미리보기가 먼저 나오고, `y`를 눌러야 실제로 옮깁니다.

> 💡 **매일 자동으로** — Windows 작업 스케줄러에 등록하면 매일 정해진 시각에 정리합니다.
> `schtasks /create /tn 다운로드정리 /sc daily /st 21:00 /tr "organize run C:\정리\config.yaml -W %USERPROFILE%\Downloads"`

> ⚠️ 규칙 파일을 메모장으로 고쳤다면 **인코딩 UTF-8**로 저장하시기 바랍니다. 띄어쓰기 하나만 틀려도 오류가 나니 `organize check config.yaml`로 먼저 검사하시기 바랍니다.

## 5. 어디에 쓰면 좋을까

- **다운로드·바탕화면이 늘 꽉 찬 사람** → 매일 자동으로 종류별 폴더로
- **영수증·고지서 PDF 모으기** → 연말정산·가계부 정리할 때 '영수증/연도' 폴더 하나만 보면 됩니다
- **사진 정리** → 연도-월 폴더로 나누고, 복사본을 골라내 용량 확보

**👎 아쉬운 점**
- 창(버튼) 화면이 없고, **규칙을 글(YAML)로** 써야 합니다
- **되돌리기 기능이 없습니다**
- 스캔 PDF(글자 없는 그림)는 내용으로 못 고릅니다
- 중복 찾기는 같은 폴더 안에서만 비교합니다(기본값)
- 마지막 새 버전이 2024년 11월(3.3.0)입니다

## 6. 자주 묻는 질문

**Q. 정말 무료입니까?**
A. 네. MIT 라이선스라 개인도 회사도 무료로 쓸 수 있습니다.

**Q. 파일이 지워지지는 않습니까?**
A. 시연 규칙은 **옮기기만** 합니다. 다만 규칙에 `delete`를 쓰면 완전히 지워지니, 지우고 싶다면 `trash`(휴지통)를 쓰는 편이 안전합니다.

**Q. 다운로드 말고 다른 폴더도 됩니까?**
A. 됩니다. 명령의 `-W` 뒤 폴더만 바꾸면 됩니다 (예: `"%USERPROFILE%\Desktop"`). 단, 프로그램·시스템 폴더는 정리 대상으로 정하지 마시기 바랍니다.

**Q. 인터넷에 파일이 올라갑니까?**
A. 아닙니다. 내 컴퓨터 안에서만 옮깁니다.
