# 자막 싱크 안 맞을 때, 소리 듣고 자동으로 맞춰 주는 무료 프로그램 ffsubsync 사용법 총정리

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 영상과 자막 파일을 넣으면, 영상 속 말소리에 맞춰 자막 시각을 옮긴 새 자막을 만들어 주는 무료 프로그램입니다.
> ⭐ 별 약 7,900 · 무료 오픈소스 · MIT 라이선스 · 파이썬

> **일반인 쓸모 ★★★★☆** — 파이썬과 ffmpeg를 깔고 명령 한 줄이면 됩니다. 끌어다 놓기 파일도 준비해 두었습니다. 준비물이 두 가지이고, 중간부터 밀린 자막은 옵션을 알아야 해서 별 하나를 뺐습니다.
> **이걸로 할 수 있는 것**
> 1. 받은 자막이 **말보다 2~3초 늦거나 빠를 때**, 소리를 듣고 **알아서 당기거나 미룬** 새 자막을 만든다
> 2. **뒤로 갈수록 점점 더 밀리는** 자막(다른 판 영상용 자막)도 한 번에 바로잡는다
> 3. 내 영상·강의 자막을 **0.1초씩 손으로 맞추던 일**을 명령 한 줄로 끝낸다

## 1. ffsubsync란 무엇입니까?

**ffsubsync**(에프에프 섭싱크)는 **어긋난 자막을 영상 소리에 맞춰 자동으로 옮겨 주는** 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**이고, 2019년부터 만들어져 GitHub에서 별 7,900개 가까이 받았습니다.

인터넷에서 받은 자막(.srt)이 말보다 2초 늦게 뜨면 보기가 무척 불편합니다. 동영상 플레이어에서 자막을 0.1초씩 당기는 방법도 있지만, 영상을 바꿀 때마다 다시 해야 합니다. ffsubsync는 **영상 소리를 직접 듣고** 몇 초를 옮겨야 하는지 찾아서 **새 자막 파일**로 저장합니다.

창이 뜨는 프로그램이 아니라 **명령 프롬프트에 한 줄**을 넣어서 씁니다. 영상에서 소리를 꺼내는 **ffmpeg**(에프에프엠펙)가 함께 필요합니다.

## 2. 비유로 쉽게 이해하기

ffsubsync는 **투명 필름 두 장을 겹쳐 맞추는 사람**입니다.

1. **소리 필름** — 영상 소리에서 **말하는 구간만 칠한** 필름
2. **자막 필름** — 자막 파일에서 **자막이 뜨는 구간만 칠한** 필름
3. 자막 필름을 **좌우로 밀어 보며** 무늬가 **가장 많이 겹치는 자리**를 찾습니다

찾은 거리만큼 자막 시각을 한꺼번에 옮깁니다. 필름을 **조금 늘이거나 줄여** 보기도 해서, 뒤로 갈수록 밀리는 자막도 맞춥니다. 반대로 소리 필름이 **비어 있으면**(소리 없는 영상) 맞출 수 없습니다.

## 3. 실제 화면으로 보기

시연용으로 만든 **60초짜리 가상 '라면 끓이는 법' 영상**(기계 목소리로 문장 10개를 읽힘)과, 정답 시각을 아는 자막을 일부러 틀어 놓은 자막으로 클라우드에서 자동으로 실행한 결과입니다. 그래픽카드 없는 보통 컴퓨터 성능(CPU 2개) 기준입니다.

[이미지: ffsubsync-anim.gif]

| 시연 내용 | 걸린 시간 | 평균 어긋남 (전 → 후) |
|---|---|---|
| 전체가 2.5초 늦은 자막 | **0.58초** | **2.50초 → 0.03초** |
| 전체가 1.7초 빠른 자막 | 0.51초 | 1.68초 → 0.21초 |
| 뒤로 갈수록 밀리는 자막 | 0.53초 | 2.00초 → **0.003초** |
| CP949(완성형) 한글 자막 | 0.58초 | 2.50초 → 0.03초 |
| 약 10분 영상 + 자막 100줄 | **1.95초** | 2.5초 어긋남을 2.46초로 찾음 |

'평균 어긋남'은 문장 10개의 시작 시각이 정답과 다른 정도의 평균입니다.

[이미지: before-after.png]

같은 9.2초 장면입니다. 고치기 전에는 2번 문장이 들리는데 화면에는 아직 1번 문장이 떠 있고, 고친 뒤에는 둘 다 2번 문장입니다.

### 놀라운 점 ① 뒤로 갈수록 밀리는 자막도 맞춥니다
다른 판(초당 25장 대 23.976장) 영상용 자막은 첫 문장은 0.86초, 마지막 문장은 3.08초 늦었습니다. 옵션 없이 기본 명령만으로 **늘이기 비율 0.959**를 찾아 10문장 모두 0.00초로 맞췄습니다.

### 놀라운 점 ② 한글 자막 인코딩을 스스로 알아봅니다
오래된 한글 자막에 많은 CP949(완성형)로 저장한 자막도 인코딩을 스스로 알아냈고, 고친 자막은 UTF-8로 저장했습니다.

### 꼭 알아 둘 점 — 중간부터만 밀린 자막
6번째 문장부터만 3초 늦은 자막을 기본 명령으로 고치면, **맞던 앞부분이 오히려 최대 1.76초 틀어졌습니다**(평균 1.50초 → 0.86초). `--split-penalty`를 붙이면 구간마다 따로 맞춰 평균 0.18초가 됐습니다.

## 4. 사용 방법 (Windows)

**준비 (처음 한 번)**
1. https://www.python.org/downloads/ 에서 파이썬 설치 — 첫 화면 아래 **'Add python.exe to PATH' 체크**
2. 명령 프롬프트(cmd)에서 설치
```cmd
:: ffmpeg 설치 (영상에서 소리를 꺼내는 프로그램)
winget install Gyan.FFmpeg
:: 명령 프롬프트를 새로 연 뒤 ffsubsync 설치
pip install ffsubsync
:: 설치 확인
ffsubsync --version
```

**자막 맞추기**
```cmd
:: 영상과 자막이 있는 폴더로 이동
cd /d D:\영상
:: 소리에 맞춘 새 자막 만들기 (원래 자막은 그대로)
ffsubsync 영상.mp4 -i 자막.srt -o 영상.srt
:: 중간부터만 밀린 자막이면
ffsubsync 영상.mp4 -i 자막.srt -o 영상.srt --split-penalty
```

[이미지: terminal.gif]

> 💡 **명령어가 어렵다면** — 저장소 폴더의 `자막맞추기.bat`을 받아 두고, 영상 파일과 자막 파일을 Ctrl을 누른 채 함께 골라 `.bat` 아이콘 위로 끌어다 놓으시기 바랍니다. 같은 폴더에 `자막이름_맞춤.srt`가 새로 생깁니다. (Windows 실행 확인 전 파일)

> 💡 **자막 이름을 영상 이름과 같게** 저장하면(`영상.mp4` → `영상.srt`) 대부분의 동영상 플레이어가 자동으로 불러옵니다.

> ⚠️ 파일 이름에 띄어쓰기가 있으면 `"내 영상.mp4"`처럼 따옴표로 감싸시기 바랍니다.

## 5. 어디에 쓰면 좋을까

- **받은 자막이 몇 초씩 어긋나는 사람** → 영상 소리에 맞춰 한 번에
- **영상에 자막을 붙이는 사람** → 편집 뒤 밀린 자막을 다시 맞추기
- **어학 공부용 영상** → 자막 싱크가 맞아야 듣기 공부가 됩니다

**👎 아쉬운 점**
- 창(버튼) 화면이 없고, **ffmpeg를 따로 설치**해야 합니다
- **소리 없는 영상**은 못 맞춥니다 (오류로 멈춤)
- 중간부터만 밀린 자막은 **옵션(`--split-penalty`)**이 필요합니다
- 시연 ②처럼 **0.2초 정도 남는** 경우가 있습니다

## 6. 자주 묻는 질문

**Q. 정말 무료입니까?**
A. 네. MIT 라이선스라 개인도 회사도 무료로 쓸 수 있습니다.

**Q. 원래 자막이 바뀌지는 않습니까?**
A. `-o` 뒤에 적은 이름으로 **새 파일**을 만듭니다. 원래 자막은 그대로입니다.

**Q. 맞는 자막이 없어도 됩니까?**
A. 됩니다. 영상 소리를 기준으로 맞춥니다. 맞는 자막이 이미 있다면 그 자막을 기준으로 맞출 수도 있습니다(시연 0.24초).

**Q. 영상이 인터넷에 올라갑니까?**
A. 아닙니다. 내 컴퓨터 안에서만 소리를 읽고 계산합니다.
