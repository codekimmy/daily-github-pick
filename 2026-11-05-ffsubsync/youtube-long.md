※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

어긋난 자막(.srt)을 영상 소리에 맞춰 자동으로 당기거나 미뤄 주는 무료 프로그램 ffsubsync. 원리, 설치(ffmpeg 포함), 늦은 자막·빠른 자막·뒤로 갈수록 밀리는 자막·한글 CP949 자막·10분 영상 시연, 중간부터 밀린 자막과 소리 없는 영상 같은 아쉬운 점까지 실제 결과로 보여 드립니다.

▶ 원본 저장소: https://github.com/smacke/ffsubsync
▶ 끌어다 놓기 파일(자막맞추기.bat)·명령어 모음: https://github.com/codekimmy/daily-github-pick/tree/main/2026-11-05-ffsubsync
▶ 설치와 사용 (cmd, 파이썬 필요)
   winget install Gyan.FFmpeg
   pip install ffsubsync
   ffsubsync 영상.mp4 -i 자막.srt -o 영상.srt                    ← 소리에 맞춘 새 자막
   ffsubsync 영상.mp4 -i 자막.srt -o 영상.srt --split-penalty    ← 중간부터 밀린 자막
※ 영상 속 자료는 기계 목소리로 만든 시연용 가상 영상이고, 시간은 그래픽카드 없는 CPU 2개 기준입니다. 고친 자막은 꼭 재생해서 확인하시기 바랍니다.
※ 유의사항
- 영상 속 결과는 2026-11-05 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- ffsubsync 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 원본 자막은 따로 보관하시기 바랍니다.
- 소리가 없거나 말소리가 작은 영상은 맞추지 못하거나 틀릴 수 있습니다. 받은 영상·자막은 개인 시청 목적으로만 쓰시기 바랍니다.
