# 메모장 가계부를 차트로 보여 주는 무료 프로그램 fava 사용법 총정리 (설치법·예산 설정 포함)

## 1. fava란 무엇입니까?

**fava**(파바)는 **메모장에 적은 가계부를 그래프와 표로 보여 주는** 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**(공개 프로그램)이고, 2015년부터 만들어져 GitHub에서 별 2,600개 정도를 받았습니다.

가계부 앱은 편하지만 내 기록이 회사 서버에 저장됩니다. 엑셀 가계부는 표가 커질수록 수식이 복잡해집니다. fava는 다른 방식을 씁니다. 가계부를 **그냥 글자 파일**(beancount 형식)로 적어 두면, fava가 그 파일을 읽어 **내 컴퓨터 안에서** 화면을 만들어 줍니다.

장부 파일을 읽고 계산하는 부분은 **beancount**(빈카운트)라는 프로그램이 맡고, fava는 그 결과를 보여 주는 화면입니다. fava를 설치하면 beancount도 함께 설치됩니다.

## 2. 비유로 쉽게 이해하기

fava는 가계부의 **자동차 계기판**입니다.

1. **엔진 = 메모장에 적은 장부 글자** — 내가 직접 적습니다. fava는 이 파일을 고치지 않습니다
2. **계기판 = fava 화면** — 장부 글자를 읽어 수입·지출·잔액을 그래프로 보여 줍니다
3. **경고등 = 오류 표시** — 합이 안 맞는 거래나 통장 잔액 차이가 있으면 빨간 '오류' 숫자가 켜집니다

장부는 이렇게 적습니다. 거래 1건이 3줄입니다.

```
2026-02-05 * "편의점" "도시락"
  Expenses:Food-식비  7300 KRW
  Liabilities:Card-카드
```

- 첫 줄: 날짜 · `*` · 가게 · 메모
- 둘째 줄: 어디에 썼나(계정)와 금액
- 셋째 줄: 돈이 나간 곳(카드). 금액을 비워 두면 -7300이 자동으로 채워져 **합이 0**이 됩니다

> 계정 이름은 **영어 대문자로 시작**해야 합니다. 시연에서 `Expenses:식비`는 오류가 났고, `Expenses:Food-식비`는 통과했습니다.

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스)에서 자동으로 실행한 **시연 결과**입니다. 장부는 **시연용으로 지어낸 가상 가계부**(2026년 2~10월, 거래 453건)입니다.

[이미지: fava-anim.gif]

**① 설치와 켜기** — 새 환경에서 설치 5.9초, 켜고 나서 화면이 응답하기까지 **0.43초**였습니다.

**② 손익계산서** — 9개월 수입 2,534만 7,000원, 지출 1,085만 6,700원이 달마다 막대로 나옵니다. 메뉴는 장부에 설정 한 줄을 넣어 한국어로 바꿨습니다.

**③ 어디에 많이 썼나** — 'Expenses'를 누르면 사각형 그래프로 바뀝니다. 칸이 클수록 많이 쓴 곳입니다. 1위 월세 585만 원, 2위 식비 299만 9,400원이었습니다.

[이미지: shots/02_expense_tree.png]

**④ 식비 예산** — 장부에 "식비 한 달 40만 원"을 한 줄 적었더니, 식비 화면에 달마다 **예산까지 남은 돈**이 괄호로 나왔습니다. 4월(42만 2,000원 → -22,000)과 10월(40만 700원 → -700)이 빨간색이었습니다.

[이미지: shots/06_food.png]

**⑤ 틀린 장부 잡아내기** — 일부러 틀린 장부 3개를 만들어 `bean-check`(장부 검사 명령)를 실행한 결과입니다.

| 틀린 내용 | 검사 결과 |
|---|---|
| 32,000원 썼는데 카드엔 23,000원 | `does not balance: (9000 KRW)` + 줄 번호 |
| 계정 이름 오타 `Fod-식비` | `unknown account` (없는 계정) |
| 통장 잔액 확인 줄과 1만 원 차이 | `10000 too little` |

[이미지: shots/11_errors.png]

**⑥ 그 밖의 시연 결과**
- 장부 검사 **0.13초**, 화면 열기 0.6~0.8초
- fava를 켠 채로 장부에 한 줄을 더하고 새로고침하니 **1.84초** 만에 새 거래가 보였습니다
- 쿼리(질문 한 줄로 표 만들기)로 월별 식비 표를 만들어 **CSV 파일**(엑셀에서 여는 파일)로 받았습니다
- 10년치 가상 장부(거래 6,475건)도 검사 0.52초, 화면 0.69초였습니다

**아쉬운 점**
- 장부 쓰는 규칙(한 거래에 계정 두 개)을 익혀야 합니다
- 은행·카드 내역을 자동으로 가져오지 않습니다
- 기본 설정은 수입이 마이너스(-)로 보입니다. 아래 설정 한 줄로 뒤집을 수 있습니다

## 4. 설치 방법 (Windows)

**1) 파이썬 설치** — https://www.python.org/downloads/ 에서 받아 설치합니다. 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다.

**2) fava 설치** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: fava 설치 (장부 프로그램 beancount도 함께 설치됨)
pip install fava
:: 설치 확인 (fava, version 1.30.16 처럼 나오면 성공)
fava --version
```

**3) 장부 만들기** — 메모장에 아래를 붙여 넣고 `가계부.beancount`로 저장합니다(인코딩 UTF-8).
```
option "title" "우리집 가계부"
option "operating_currency" "KRW"
2026-01-01 custom "fava-option" "language" "ko"
2026-01-01 custom "fava-option" "invert-income-liabilities-equity" "true"

2026-01-01 open Assets:Bank-통장 KRW
2026-01-01 open Liabilities:Card-카드 KRW
2026-01-01 open Income:Salary-월급 KRW
2026-01-01 open Expenses:Food-식비 KRW
2026-01-01 open Equity:Opening-시작잔액 KRW

2026-01-01 custom "budget" Expenses:Food-식비 "monthly" 400000 KRW

2026-01-01 * "시작 잔액"
  Assets:Bank-통장  1500000 KRW
  Equity:Opening-시작잔액

2026-01-26 * "동네마트" "장보기"
  Expenses:Food-식비  52000 KRW
  Liabilities:Card-카드
```

**4) 검사하고 켜기**
```cmd
:: 장부가 있는 폴더로 이동 (예: D:\가계부)
cd /d D:\가계부
:: 장부 검사 (아무 말도 없으면 통과)
bean-check 가계부.beancount
:: 화면 켜기 → 브라우저에서 http://127.0.0.1:5000 열기 (끄기: Ctrl+C)
fava 가계부.beancount
```

명령어가 어렵다면 저장소의 `가계부열기.bat`에 장부 파일을 **끌어다 놓기만** 하면 됩니다(Windows 실행 확인 전 파일).

## 5. 어디에 쓰면 좋을까

- **엑셀 가계부가 복잡해진 분** — 글자로 적고 그래프는 fava에 맡깁니다
- **가계부를 인터넷 서비스에 올리기 싫은 분** — 내 컴퓨터 안의 파일 하나로 관리합니다
- **식비·카페값이 늘 궁금한 분** — 예산을 적어 두고 넘은 달만 확인합니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. fava는 MIT, beancount는 GPL-2.0 라이선스의 무료 오픈소스입니다.

**Q. 은행·카드 내역을 자동으로 불러옵니까?**
A. 기본으로는 아닙니다. 직접 적어야 합니다. '가져오기' 메뉴는 따로 설정이 필요하며 이번 시연에서는 다루지 않았습니다.

**Q. 계정 이름을 한글로만 쓸 수 있습니까?**
A. 안 됩니다. 시연에서 `Expenses:식비`는 오류가 났습니다. `Expenses:Food-식비`처럼 영어 대문자로 시작하면 됩니다.

**Q. 휴대폰에서도 볼 수 있습니까?**
A. fava는 내 컴퓨터에서 켜는 화면입니다. 휴대폰 앱은 아닙니다.

**Q. 가계부가 인터넷에 올라갑니까?**
A. 아닙니다. 내 컴퓨터 안의 장부 파일만 읽습니다.
