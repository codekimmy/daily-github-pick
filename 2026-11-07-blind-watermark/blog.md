# 사진에 안 보이는 글자를 숨기는 무료 프로그램 blind_watermark 사용법 총정리 (설치법·한계 포함)

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 사진 전체에 아주 옅은 변화를 흩어 넣어 눈으로는 안 보이는 글자를 숨기고, 숫자 두 개로 다시 꺼내는 무료 프로그램입니다.

> **일반인 쓸모 ★★★☆☆** — `pip install blind-watermark` 한 줄로 설치되고 명령 한 줄로 글자를 넣고 꺼냅니다. 다만 꺼낼 때 숫자를 따로 적어 둬야 하고, 명령어의 비밀번호가 잠금 역할을 하지 않으며, 강한 압축·밝기 변경·돌림에는 글자가 깨져 별 두 개를 뺐습니다.

> 3. 거래처마다 **다른 글자**를 숨겨 보내, 사진이 어디서 퍼졌는지 찾는 데 참고한다

## 1. blind_watermark란 무엇입니까?

**blind_watermark**(블라인드 워터마크)는 사진에 **눈에 보이지 않는 워터마크**(사진 주인 표시)를 넣는 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**(공개 프로그램)이고, 2019년부터 개인 개발자 guofei9987가 만들어 GitHub에서 별 1만 4천여 개를 받았습니다.

보통 워터마크는 사진 구석에 글씨를 얹습니다. 눈에 거슬리고, 잘라 내면 사라집니다. blind_watermark는 글자를 **사진 전체에 아주 옅게 흩어** 넣습니다. 그래서 겉으로는 원본과 똑같아 보이지만, 숫자 두 개를 알면 숨긴 글자를 다시 꺼낼 수 있습니다. 이름의 'blind'는 **원본 사진 없이도** 꺼낼 수 있다는 뜻입니다.

## 2. 비유로 쉽게 이해하기

blind_watermark는 **투명 잉크로 찍는 '숨은 도장'**입니다.

1. **보통 워터마크 = 잉크 도장** — 잘 보이지만, 지우거나 잘라 내면 끝입니다
2. **숨은 도장 = 투명 잉크** — 사진 전체에 옅게 찍혀 눈으로는 안 보입니다
3. **자외선 등 = 숫자 두 개** — 넣을 때 정한 비밀번호와, 넣을 때 알려 주는 글자 길이(예: 136)가 있어야 보입니다

투명 잉크도 종이를 심하게 구기면 번지듯, 사진을 **강하게 압축하거나 밝기를 바꾸면** 도장이 깨질 수 있습니다. 이 부분은 아래 시연 결과에서 자세히 보여 드립니다.

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 자동으로 실행한 **시연 결과**입니다. 사진은 저작권 없는 예제 사진(scikit-image의 고양이·커피 CC0, 우주인·로켓 퍼블릭 도메인)이고, 숨긴 글자는 `ⓒ내사진 2026`입니다.

[이미지: bw-anim.gif]

**① 넣기와 꺼내기** — 고양이 사진(451×300)에 넣는 데 **0.18초**, 꺼내는 데 **0.12초**였습니다. 사진 4장 모두 글자가 그대로 나왔습니다.

**② 정말 안 보입니까?** — 원본과 도장 넣은 사진의 색 값 차이는 0~255 중 **평균 2.47**이었습니다. 차이만 30배로 키워 보면 사진 전체에 고르게 흩어져 있습니다.

[이미지: before-after.png]

**③ 사진을 망가뜨려도 나옵니까?** — 15가지로 사진을 망가뜨려 본 결과, 고양이·우주인 사진 모두 **15가지 중 10가지**에서 글자가 그대로 나왔습니다.

| 시연 | 고양이 | 우주인 |
|---|---|---|
| JPG 화질 90·70·50으로 다시 저장 | ✔ | ✔ |
| JPG 화질 30 | ✘ | ✘ |
| 절반 크기로 줄임 (원래 크기로 늘려서 꺼냄) | ✔ | ✔ |
| 사진 일부 가림 · 큰 글씨 덧씀 · 점 잡음 1% | ✔ | ✔ |
| 메신저 전송 흉내 (75% 축소 + JPG 85) | ✔ | ✘ |
| 어둡게 80% / 밝게 120% | ✘ / ✘ | ✘ / ✔ |
| 10도 돌린 채로 / 다시 돌려 놓고 | ✘ / ✔ | ✘ / ✔ |
| 잘라 낸 채로 / 원래 자리 찾아 복원 후 | ✘ / ✔ | ✘ / ✔ |

같은 편집이라도 **사진마다 결과가 달랐습니다.** 잘라 낸 사진은 도장 넣은 사진과 비교해 원래 자리를 찾아야 하므로, 도장 넣은 사진을 갖고 있어야 합니다.

**④ 비밀번호의 함정** — 명령어로 `--pwd 1234`를 넣고 **9999나 1로 꺼내도 글자가 그대로** 나왔습니다. 명령어의 비밀번호는 '사진 섞는 번호'만 바꾸고 글자를 잠그지 않습니다. 파이썬으로 **글자 비밀번호**(`password_wm`)를 따로 정하면 틀린 번호로는 깨진 글자만 나왔습니다.

[이미지: terminal.gif]

**⑤ 그 밖의 시연 결과**
- 글자 길이 숫자를 136 대신 128·144로 넣으면 깨진 글자가 나왔습니다
- 고양이 사진에는 한글 60자까지 들어갔고, 100자는 '넘침' 오류가 났습니다
- 48×48 흑백 로고 그림도 숨길 수 있었습니다 (꺼낸 그림 99.9% 일치, JPG 화질 50 뒤 85.1%)
- 휴대폰 사진 크기(4032×3024)는 넣기 16.9초, 꺼내기 11.46초가 걸렸습니다

**아쉬운 점**
- 꺼낼 때 **글자 길이 숫자**를 알아야 합니다
- 명령어의 `--pwd`는 잠금 역할을 하지 않습니다
- 창 화면이 없고 명령어로만 씁니다
- 마지막 새 버전(0.4.4)이 2023년 4월에 나왔습니다

## 4. 설치 방법 (Windows)

**1) 파이썬 설치** — https://www.python.org/downloads/ 에서 받아 설치합니다. 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다.

**2) blind-watermark 설치** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 설치 (사진 처리 도구 OpenCV 등 약 250MB가 함께 설치됨)
pip install blind-watermark
:: 설치 확인 (Version: 0.4.4 처럼 나오면 성공)
pip show blind-watermark
```

**3) 넣고 꺼내기** — 사진은 **영어 이름 폴더·파일**에 두는 것이 안전합니다. 사진 처리 도구 OpenCV가 Windows에서 한글 경로를 못 여는 경우가 알려져 있습니다.
```cmd
:: 사진이 있는 폴더로 이동 (예: D:\photo)
cd /d D:\photo
:: 넣기: photo.png 에 글자를 숨겨 stamp.png 로 저장
blind_watermark --embed --pwd 1234 photo.png "ⓒ내사진 2026" stamp.png
:: → 마지막 줄 "Put down watermark size: 136" 의 숫자를 꼭 적어 두기
:: 꺼내기
blind_watermark --extract --pwd 1234 --wm_shape 136 stamp.png
```

글자를 비밀번호로 잠그고 싶다면 저장소의 `글자도장.py`를 받아 아래처럼 씁니다(Windows 실행 확인 전 파일).
```cmd
:: 넣기 (마지막 5678 = 글자 비밀번호)
python 글자도장.py 넣기 photo.png "ⓒ내사진 2026" stamp.png 5678
:: 꺼내기 (글자 길이 숫자, 글자 비밀번호)
python 글자도장.py 꺼내기 stamp.png 136 5678
```

## 5. 어디에 쓰면 좋을까

- **사진을 블로그·쇼핑몰에 올리는 분** — 보이는 워터마크 없이 '내 사진' 표시를 숨겨 둡니다
- **거래처에 제품 사진을 보내는 분** — 받는 곳마다 다른 글자를 넣어 두고, 퍼진 사진에서 꺼내 봅니다
- **사진 도용이 걱정되는 분** — 의심되는 사진에서 내 글자가 나오는지 확인하는 참고 자료로 씁니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. MIT 라이선스의 무료 오픈소스입니다.

**Q. 한글도 숨길 수 있습니까?**
A. 네. 시연에서 `ⓒ내사진 2026`을 넣고 그대로 꺼냈습니다.

**Q. 사진 화질이 나빠집니까?**
A. 색 값 차이는 평균 2.4~2.6(0~255 중)이었습니다. 어느 정도면 괜찮은지는 직접 보고 판단하시기 바랍니다.

**Q. 카카오톡으로 보낸 사진에서도 꺼낼 수 있습니까?**
A. 실제 메신저로는 시연하지 않았습니다. 비슷하게 흉내 낸 시연(75% 축소 + JPG 85)에서는 고양이 사진은 성공, 우주인 사진은 실패했습니다.

**Q. 도용을 막아 줍니까?**
A. 아닙니다. 숨긴 글자를 확인하는 수단일 뿐, 도용을 막거나 법적 증거를 보장하지 않습니다.

## 마무리

명령 한 줄로 **눈에 안 보이는 글자**를 사진에 숨기고 다시 꺼낼 수 있습니다. 다만 숫자(글자 길이)를 적어 두고, 명령어 비밀번호가 잠금이 아니라는 점, 강한 편집에는 약하다는 점을 알고 쓰시기 바랍니다.
