▶ 설치와 사용 (cmd, 파이썬 필요, 사진·폴더 이름은 영어로)
   pip install blind-watermark
   blind_watermark --embed --pwd 1234 photo.png "ⓒ내사진 2026" stamp.png      ← 넣기 (마지막 줄 숫자 적어 두기)
   blind_watermark --extract --pwd 1234 --wm_shape 136 stamp.png              ← 꺼내기
▶ 그림 도장 (파이썬)
   from blind_watermark import WaterMark
   bwm = WaterMark(password_img=1, password_wm=5678)
   bwm.read_img("photo.png"); bwm.read_wm("logo.png", mode="img"); bwm.embed("stamp.png")
※ 영상 속 사진은 저작권 없는 예제 사진(scikit-image, CC0·퍼블릭 도메인)이고, 시간은 그래픽카드 없는 CPU 2개 기준입니다.
※ 유의사항
- 영상 속 결과는 2026-11-07 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- blind_watermark 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 원본 사진은 따로 보관하시기 바랍니다.
- 숨은 도장은 사진 도용을 막거나 법적 증거를 보장하지 않습니다. 남이 찍은 사진에 내 도장을 넣어 쓰지 않도록 주의하시기 바랍니다.
