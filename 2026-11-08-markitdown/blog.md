# 워드·엑셀·PDF를 AI가 읽기 좋은 글로 바꾸는 무료 프로그램 markitdown 사용법 총정리 (설치법·한계 포함)

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 워드·엑셀·파워포인트·PDF에서 꾸밈은 빼고 글·표·목록만 꺼내 글 파일(마크다운)로 저장하는 Microsoft의 무료 프로그램입니다.
> ⭐ 별 약 19.4만 · 무료 오픈소스 · MIT 라이선스 · 파이썬

> **일반인 쓸모 ★★★★☆** — `pip install "markitdown[all]"` 한 줄로 설치되고, 문서 하나를 명령 한 줄에 1초 안팎으로 글로 바꿉니다. 다만 스캔한 PDF·사진 속 글자는 못 읽고, 한글 문서(HWP)는 지원 목록에 없으며, 창 화면 없이 명령어로만 써서 별 하나를 뺐습니다.
> **이걸로 할 수 있는 것**
> 1. 긴 보고서·회의록을 **글로 바꿔 AI 대화창에 붙여 넣고** 요약을 부탁한다
> 2. 흩어진 워드·PDF 안내문을 **글 파일로 모아** 메모장에서 검색한다
> 3. 파워포인트에서 **발표자 메모만 뽑아** 발표 대본으로 정리한다

## 1. markitdown이란 무엇입니까?

**markitdown**(마크잇다운)은 여러 종류의 문서를 **마크다운**(제목·목록·표를 `#`, `*`, `|` 같은 기호로 표시하는 글 형식)으로 바꿔 주는 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**(공개 프로그램)이고, 미국 Microsoft가 2024년 11월에 공개해 GitHub에서 별 19만 개 넘게 받았습니다.

워드·엑셀·파워포인트·PDF·웹페이지·CSV·전자책(EPUB)·ZIP 묶음까지 **명령 한 줄**로 바꿉니다. 만든 곳은 이 도구를 **AI(대화형 인공지능)에게 문서를 건네기 위한 도구**라고 소개합니다. 사람이 보기 좋은 문서를 만드는 도구가 아니라, 글과 표의 **뼈대만 남기는** 도구입니다.

## 2. 비유로 쉽게 이해하기

markitdown은 문서의 **포장을 벗기는 '포장 뜯개'**입니다.

1. **워드 파일 = 선물 상자** — 알맹이(글·표)보다 포장(글꼴·색·여백·쪽 설정)이 훨씬 큽니다. 시연에 쓴 회의록은 36.4KB였는데 알맹이 글은 **0.85KB**였습니다
2. **markitdown = 포장 뜯개** — 포장지를 벗기고 알맹이만 꺼내 **투명 봉투(마크다운)**에 담습니다. 제목에는 `#`, 목록에는 `*`, 표에는 `|` 이름표를 붙여 모양은 남겨 둡니다
3. **투명 봉투 = AI가 읽기 쉬운 글** — 메모장으로도 열리고, 그대로 복사해 AI 대화창에 붙여 넣을 수 있습니다

포장 뜯개는 **상자 안에 실제로 든 것**만 꺼냅니다. 스캔한 PDF처럼 글자가 **사진으로 찍혀** 있으면 꺼낼 글이 없어 빈 봉투가 나옵니다. 이 부분은 아래 시연 결과에서 보여 드립니다.

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 자동으로 실행한 **시연 결과**입니다. 문서는 모두 **시연용으로 만든 가상 자료**(가상 꽃집 회의록, 가상 가계부 등)입니다. 시간에는 프로그램을 켜는 시간(약 0.8초)이 포함됩니다.

[이미지: md-anim.gif]

**① 워드 회의록** — 36.4KB 워드 파일이 **1.04초** 만에 0.85KB 글로 바뀌었습니다. 소제목은 `#`, 목록은 `*`, 굵은 글씨는 `**`, 표는 `|`로 남았습니다. 다만 맨 위 큰 제목은 `#` 없이 나왔고, 표의 머리줄이 한 칸 밀렸습니다.

[이미지: before-after.png]

**② 문서 종류별 결과**

| 문서 | 시간 | 결과 |
|---|---|---|
| 엑셀 가계부 (시트 2개) | 0.9초 | ✔ 시트마다 제목 + 표. 빈칸은 `NaN` 글자로 |
| 파워포인트 (3장) | 0.87초 | ✔ 슬라이드별 제목·글, **발표자 메모**, 표 |
| PDF 공지문 | 0.95초 | ✔ 글·목록·표 / ✘ 제목 표시·링크 주소 사라짐 |
| 웹페이지(HTML) | 0.85초 | ✔ 제목·목록·표·링크. 메뉴·바닥글도 같이 나옴 |
| 윈도우 엑셀 한글 CSV | 0.84초 | ✔ 한글 깨짐 없이 표로 |
| 전자책(EPUB) | 0.8초 | ✔ 제목·저자·목차·본문 |
| ZIP (파일 3개 묶음) | 1.05초 | ✔ 파일마다 나눠 한 글로 (1,800자) |
| **스캔한 PDF** | 0.79초 | ✘ **0자** |
| **글자가 찍힌 사진** | 0.77초 | ✘ **0자** |

[이미지: terminal.gif]

**③ 큰 파일** — 100쪽 PDF는 **9.78초**(문단 1,400개 모두), 1만 줄 엑셀은 **3.5초**(1만 줄 모두), 50장 파워포인트는 **0.93초**(제목 50개 모두)였습니다. 엑셀은 칸마다 `|` 기호가 붙어 글이 오히려 커졌습니다(188KB → 303KB).

**④ 폴더 통째로** — 문서 8개가 든 폴더를 파이썬 예제로 한 번에 바꾸는 데 **0.4초**가 걸렸습니다. 프로그램을 한 번만 켜기 때문에 하나씩 바꿀 때보다 빠릅니다.

**아쉬운 점**
- **스캔본·사진 속 글자는 못 읽습니다** (사진 설명은 유료 AI 서비스 연결이 필요하다고 프로그램 설명에 있습니다. 이번 시연에서는 쓰지 않았습니다)
- **한글 문서(HWP)는 변환기 목록에 없습니다** (실제 HWP 파일로는 시연하지 않았습니다)
- 엑셀 빈칸 `NaN`, 워드 표 머리줄 밀림, PDF 제목 표시 사라짐처럼 **모양이 조금씩 어긋납니다**
- 창 화면이 없고 명령어로만 씁니다. 전부 설치하면 약 330MB입니다

## 4. 설치 방법 (Windows)

**1) 파이썬 설치** — https://www.python.org/downloads/ 에서 받아 설치합니다(3.10 이상). 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다.

**2) markitdown 설치** — 명령 프롬프트(cmd)를 열고 입력합니다. 따옴표까지 그대로 입력하시기 바랍니다.
```cmd
:: 설치 ([all]을 붙여야 워드·엑셀·파워포인트·PDF가 모두 됨, 약 330MB)
pip install "markitdown[all]"
:: 설치 확인 (markitdown 0.1.9 처럼 나오면 성공)
markitdown --version
```

**3) 문서 바꾸기** — 결과는 `-o`로 **파일에 저장**하는 것이 안전합니다. Windows 명령 프롬프트 화면은 한글이 깨져 보일 수 있습니다.
```cmd
:: 문서가 있는 폴더로 이동 (예: D:\docs)
cd /d D:\docs
:: 워드 → 글 파일 (-o 뒤에 저장할 이름)
markitdown 회의록.docx -o 회의록.md
:: PDF도 똑같이
markitdown 안내문.pdf -o 안내문.md
:: 결과를 메모장으로 열기
notepad 회의록.md
```

**4) 폴더 안 문서를 한 번에** — 예제 파일 `폴더변환.bat`(아래 링크)을 문서 폴더에 넣고 두 번 누르면 `md` 폴더에 글 파일이 만들어집니다. 원본은 바꾸지 않습니다. (Windows 실행 확인 전 파일)

## 5. 어디에 쓰면 좋을까

- **보고서·회의록을 AI로 요약하는 분** — 워드·PDF를 글로 바꿔 대화창에 붙여 넣습니다. 회사 보안 규칙을 먼저 확인하시기 바랍니다
- **공지·안내문 PDF가 쌓인 분** — 글 파일로 모아 두면 메모장 검색으로 찾을 수 있습니다
- **발표를 준비하는 분** — 파워포인트 발표자 메모만 뽑아 대본으로 정리합니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. MIT 라이선스의 무료 오픈소스입니다. 기본 변환은 인터넷 서비스 없이 내 컴퓨터에서 이루어집니다.

**Q. 한글 문서(HWP)도 됩니까?**
A. 변환기 목록에 없습니다. 한글 프로그램에서 워드(.docx)나 PDF로 저장한 뒤 바꾸시기 바랍니다.

**Q. 스캔한 PDF는 됩니까?**
A. 시연에서는 **0자**였습니다. 글자가 사진으로 찍힌 PDF는 글자 인식(OCR) 프로그램을 먼저 거쳐야 합니다.

**Q. 원본 파일이 바뀝니까?**
A. 시연에서는 원본은 그대로였고, `-o`로 정한 새 파일만 만들어졌습니다.

**Q. 표도 남습니까?**
A. 워드·엑셀·파워포인트·PDF·웹페이지의 표가 모두 `|` 표로 나왔습니다. 다만 워드는 머리줄이 한 칸 밀렸습니다.

## 마무리

명령 한 줄로 워드·엑셀·파워포인트·PDF를 **AI가 읽기 좋은 글**로 바꿀 수 있습니다. 다만 스캔본·사진 속 글자와 한글 문서(HWP)는 안 되고, 바뀐 글은 원본과 비교해 보고 쓰시기 바랍니다.

- 별 수·버전·기능은 작성 시점 기준이며 바뀔 수 있습니다. 설치 전에 공식 저장소를 꼭 확인하시기 바랍니다.
- 이 채널은 markitdown 제작자(Microsoft)와 관련이 없고, 광고·제휴가 아닙니다. 프로그램은 제작자의 라이선스(MIT)를 따릅니다.
- 프로그램 설치·사용으로 생기는 문제(파일 손상, 데이터 손실, 보안 문제 등)의 책임은 사용자에게 있습니다. 중요한 파일은 먼저 백업하고, 공식 저장소에서만 받으시기 바랍니다.
- 바뀐 글은 **빠지거나 어긋난 내용이 있을 수 있습니다.** 원본 문서는 따로 보관하고, 중요한 숫자·내용은 원본과 비교하시기 바랍니다.
- 바뀐 글을 AI 서비스에 올리면 **그 내용이 외부 서버로 전송**됩니다. 개인정보·회사 기밀이 든 문서는 올리지 않도록 주의하시기 바랍니다.
