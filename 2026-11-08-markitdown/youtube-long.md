▶ 설치와 사용 (cmd, 파이썬 3.10 이상 필요)
   pip install "markitdown[all]"
   markitdown 회의록.docx -o 회의록.md      ← 워드 → 글 파일
   markitdown 안내문.pdf -o 안내문.md        ← PDF도 똑같이
   notepad 회의록.md                        ← 메모장으로 열기
▶ 파이썬
   from markitdown import MarkItDown
   print(MarkItDown().convert("회의록.docx").text_content)
※ 영상 속 문서는 모두 시연용으로 만든 가상 자료이고, 시간은 그래픽카드 없는 CPU 2개 기준(프로그램 켜는 시간 포함)입니다.
