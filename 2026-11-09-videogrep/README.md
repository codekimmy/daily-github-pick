> 3. 내 발표 영상에서 **"음", "그러니까" 같은 말버릇만 모아** 몇 번 했는지 확인한다

## 한 줄 요약
영상의 자막 파일(.srt)에서 낱말을 찾고, 그 자막이 나오는 **구간만 잘라 새 영상 하나로 이어 붙이는** 프로그램입니다. 이렇게 만든 영상을 **슈퍼컷**(supercut, 같은 말이 나오는 장면 모음)이라고 부릅니다.

## 비유로 이해하기 — 영상용 'Ctrl+F 가위'
- 문서에서는 **Ctrl+F**(찾기)로 낱말을 찾습니다. 하지만 영상은 글이 아니라서 찾기가 안 됩니다.
- 자막 파일에는 **"0분 26초~0분 31초: 소금은 마지막에…"**처럼 줄마다 **시각**이 적혀 있습니다. videogrep은 이 자막을 **찾아보기 목록**처럼 씁니다.
- 낱말이 든 자막 줄을 찾으면, 그 줄의 시각대로 영상을 **가위로 오려** 새 영상에 차례로 붙입니다.
- 가위는 **자막 한 줄 단위**로 자릅니다. 자막이 없으면 찾을 곳이 없어 아무것도 오리지 못합니다.

## 왜 주목받나
- 영화·뉴스에서 같은 말만 모은 **슈퍼컷 영상**을 명령 한 줄로 만들 수 있어, 2014년부터 꾸준히 쓰인 프로그램입니다
- 강의·회의·인터뷰 녹화가 많아지면서 **긴 영상에서 필요한 부분만 찾는 일**이 늘었습니다
- 영상 처리 도구(ffmpeg)가 함께 설치되어 **따로 설치할 것이 적습니다** (리눅스에서 확인)

## 시연 결과 (클라우드 자동 실행)
작업 공간(리눅스, CPU 2개, 그래픽카드 없음)에서 `pip install videogrep`(2.3.0)으로 설치해 자동으로 실행한 결과입니다.
영상은 모두 **시연용으로 만든 가상 영상**입니다(`demo/make_videos.py` — 가상 '주민센터 온라인 요리 교실' 2분 31초·자막 32줄, 가상 '동네 작은도서관 회의' 1분 36초·자막 20줄. 목소리는 인터넷 없이 도는 기계 음성 espeak-ng. 실제 기관·사람과 관련 없음). 화면 오른쪽 위에 **원본 시각**을 새겨 두어, 결과 영상에서 어느 부분이 뽑혔는지 보이게 했습니다.
'찾기만'은 3번 실행한 가운데 값, '영상 만들기'는 1번 잰 값이며 **프로그램을 켜는 시간(약 0.7초)이 포함**됩니다.

| 시연 내용 | 결과 |
|---|---|
| ① 설치 (새 폴더, 내려받기 포함) | **19.0초 · 315MB** (영상 처리 도구 ffmpeg 실행 파일 165MB, 영어 받아쓰기 모델 68MB 포함) |
| ② 요리 강의에서 `소금` 찾기만 (`--demo`) | **0.7초**, 자막 32줄 중 **4줄** (원본 시각·자막 글이 한 줄씩 나옴) |

| ④ 말버릇 `^음,` (줄 맨 앞의 '음,'만) | 5장면 → 20.9초 영상, 9.9초 |
| ⑤ 회의 녹화에서 `결정` | 4장면(정원·예산·안내문·다음 회의) → 17.4초 영상, 8.38초 |

| ⑧ 앞뒤 여유 0.5초 (`-p 0.5`) | 붙어 있던 두 장면이 하나로 합쳐져 **4 → 3장면**, 20.6초 |

| ⑫ 편집 프로그램용 목록 (`-o 결정.xml`) | **0.96초** (영상은 안 만들고 장면 목록만). 문서에는 프리미어·다빈치 리졸브용이라고 적혀 있음 — **편집 프로그램에서 열어 보지는 않음** |
| ⑬ 재생 목록 (`-o 결정.m3u`) | 0.76초. 목록 안에 영상 **이름만** 적혀서, 영상과 **같은 폴더**에 저장해야 재생됨 |
| ⑭ 많이 나온 낱말 순위 (`--ngrams 1`) | 0.7초. 요리 강의 1위는 **'음'·'반' (5번씩)** / 회의 두 낱말 묶음 1위는 '독서 교실'(3번) |
| ⑮ 30분 영상 (요리 강의 12번 이어 붙임, 자막 384줄) | 찾기만 **0.68초**, 48장면 이어 붙이기 **148초**(결과 3분 23초) — 장면이 많을수록 오래 걸림 |
| ⑯ 폴더 안 영상에서 찾아 목록 만들기 (파이썬 예제 `demo/폴더에서찾기.py`) | 영상 2개에서 4장면, **0.02초** → 엑셀에서 열리는 CSV |
| ⑰ 자막 파일이 없는 영상 | `No subtitle file found` → **0장면** |
| ⑱ 낱말 하나만 자르기 (`-st fragment`) | `Could not find word-level timestamps` → **실패** (낱말마다 시각이 적힌 자막이 필요) |
| ⑲ 자동 받아쓰기 (`--transcribe`, `pip install vosk` 후) | 24.2초 만에 끝났지만 **들어 있는 모델이 영어용**이라 한국어 기계 음성을 `"the on party your own…"` 같은 영어 낱말로 받아씀. 한국어 모델은 작업 공간에서 **내려받기가 막혀**(접속 거부) 시연하지 못함 |

## Windows에서 따라하기

**준비 (처음 한 번)**
1. https://www.python.org/downloads/ 에서 파이썬을 받아 설치 — 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**
2. 명령 프롬프트(cmd)를 열고 설치
```cmd
:: videogrep 설치 (약 315MB, 영상 처리 도구 ffmpeg가 함께 설치됨 — 리눅스 기준)
pip install videogrep
:: 설치 확인 (videogrep 2.3.0 처럼 나오면 성공)
videogrep --version
```

**영상과 자막 준비** — 같은 폴더에 **이름이 똑같은** 영상과 자막을 둡니다
```
D:\영상\강의.mp4
D:\영상\강의.srt     ← 이름이 같아야 함 (강의_자막.srt 는 못 찾음)
```

**장면 찾고 모으기**
```cmd
:: 영상이 있는 폴더로 이동
cd /d D:\영상
:: 1) 찾기만 (영상은 안 만들고, 찾은 자막 줄과 시각만 보여 줌)
videogrep -i 강의.mp4 -s 시험 --demo
:: 2) 찾은 장면만 이어 붙여 새 영상으로 저장 (-o 뒤에 저장할 이름)
videogrep -i 강의.mp4 -s 시험 -o 시험모음.mp4
:: 3) 여러 낱말 중 하나라도 (| 로 나누고 따옴표로 감싸기)
videogrep -i 강의.mp4 -s "시험|중요" -o 복습.mp4
:: 4) 앞뒤로 0.5초씩 여유를 두어 말이 잘리지 않게
videogrep -i 강의.mp4 -s 시험 -p 0.5 -o 시험모음.mp4
:: 5) 영상 여러 개에서 한꺼번에
videogrep -i 1강.mp4 2강.mp4 3강.mp4 -s 시험 -o 시험모음.mp4
:: 6) 많이 나온 낱말 순위
videogrep -i 강의.mp4 --ngrams 1
```
- 결과 영상은 지금 폴더에 저장됩니다. 원본 영상은 바뀌지 않습니다(시연에서 확인)
- 파일 이름에 띄어쓰기가 있으면 `"1강 녹화.mp4"`처럼 따옴표로 감쌉니다

**물어보는 대로 실행하는 파일** — `demo/tools_win/장면모으기.bat`을 영상 폴더에 넣고 두 번 누르면 영상 이름과 낱말을 물어본 뒤 `모음_낱말.mp4`를 만듭니다 (Windows 실행 확인 전)

**폴더 안 영상에서 찾은 장면 목록(엑셀)** — `demo/폴더에서찾기.py`
```cmd
:: D:\영상 안의 모든 영상(같은 이름 .srt 있는 것)에서 "시험" 찾기 → 찾은장면_시험.csv
python 폴더에서찾기.py D:\영상 시험
:: 장면을 이어 붙인 영상도 만들려면 --make
python 폴더에서찾기.py D:\영상 시험 --make
```

**자막 파일은 어디서 구합니까?**
- 내가 찍은 영상이면 자막 만들기 프로그램이나 영상 편집 프로그램에서 **.srt로 내보내기**를 합니다
- 온라인 강의 사이트가 자막 파일 받기를 제공하면 그 파일을 씁니다 (이용 약관을 먼저 확인)
- videogrep의 자동 받아쓰기(`--transcribe`)는 **영어 모델만 들어 있습니다** (시연 ⑲)

- 장면이 많으면 영상 만들기가 오래 걸립니다. 먼저 `--demo`로 장면 수를 확인하시기 바랍니다
