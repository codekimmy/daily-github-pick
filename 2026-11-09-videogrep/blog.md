## 1. videogrep이란 무엇입니까?

**videogrep**(비디오그렙)은 영상의 **자막 파일**(.srt — 줄마다 시작 시각·끝 시각·대사가 적힌 글 파일)에서 낱말을 찾고, 그 자막이 나오는 구간만 잘라 **새 영상 하나로 이어 붙이는** 프로그램입니다. 이름의 grep(그렙)은 '글에서 낱말 찾기'를 뜻하는 컴퓨터 명령 이름입니다.

이렇게 같은 말이 나오는 장면만 모은 영상을 **슈퍼컷**(supercut)이라고 부릅니다. 미국의 예술가·교육자 Sam Lavigne(샘 라빈)이 2014년에 만들어 소스를 공개했고, GitHub에서 별 약 3,500개를 받았습니다.

중요한 점은 **소리를 듣는 프로그램이 아니라 자막을 읽는 프로그램**이라는 것입니다. 그래서 영상과 **이름이 똑같은 자막 파일**이 옆에 있어야 합니다(`강의.mp4` + `강의.srt`).

## 2. 비유로 쉽게 이해하기

videogrep은 **영상용 'Ctrl+F 가위'**입니다.

1. **Ctrl+F** — 문서에서는 Ctrl+F로 낱말을 찾지만, 영상은 글이 아니라서 찾을 수 없습니다
2. **자막 = 찾아보기 목록** — 자막에는 "0분 26초~0분 31초: 소금은 마지막에…"처럼 줄마다 시각이 적혀 있습니다. videogrep은 여기서 낱말을 찾습니다
3. **가위** — 찾은 줄의 시각대로 영상을 오려, 새 영상에 차례로 붙입니다

가위는 **자막 한 줄 단위**로 자릅니다. 자막이 없으면 찾을 곳이 없어 아무것도 오리지 못합니다.

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 자동으로 실행한 **시연 결과**입니다. 영상은 모두 **시연용으로 만든 가상 영상**(기계 음성으로 만든 가상 요리 강의 2분 31초, 가상 도서관 회의 1분 36초)입니다. 화면 오른쪽 위에 **원본 시각**을 새겨 두어, 결과 영상에서 어느 부분이 뽑혔는지 보이게 했습니다.

[이미지: vg-anim.gif]

**① 요리 강의에서 '소금'만** — 자막 32줄 가운데 '소금'이 나온 **4줄**을 0.7초 만에 찾았습니다. 이어 붙인 영상은 **150.7초 → 16.9초**, 만드는 데 **8.24초**가 걸렸습니다. 결과 영상을 보면 원본 시각이 0:26 → 1:34 → 1:39 → 2:13으로 건너뜁니다.

[이미지: terminal.gif]

**② 낱말을 바꿔 찾은 결과**

| 찾은 말 | 영상 | 결과 |
|---|---|---|
| `^음,` (줄 맨 앞의 '음,') | 요리 강의 | 5장면 → 20.9초 |
| `결정` | 회의 녹화 | 4장면(정원·예산·안내문·다음 회의) → 17.4초 |
| `예산\|만 원` (둘 중 하나라도) | 회의 녹화 | 5장면 → 23초 |
| `마지막` | 강의 + 회의 한꺼번에 | 4장면 → 14.8초 |
| `소금` | 30분 영상(자막 384줄) | 찾기 0.68초, 48장면 이어 붙이기 **148초** |

**③ 쓸 만한 옵션**
- `-p 0.5` — 장면 앞뒤로 0.5초씩 여유. 붙어 있던 두 장면이 하나로 합쳐져 4장면이 3장면이 됐습니다
- `-m 2` — 앞에서부터 2장면만 (9.2초)
- `--export-clips` — 장면을 파일 하나씩 따로 저장 (4개)
- `--export-vtt` — 새 영상에 맞춘 자막 파일도 함께 (시각 표시 형식이 보통과 조금 다름)
- `-o 이름.xml` — 영상 대신 편집 프로그램용 장면 목록을 0.96초에 (문서 기준 프리미어·다빈치 리졸브용, 이번 시연에서는 열어 보지 않음)
- `--ngrams 1` — 많이 나온 낱말 순위. 요리 강의는 '음'과 '반'이 5번씩으로 공동 1위였습니다

**아쉬운 점**
- **자막 파일이 없으면 0장면**입니다 (`No subtitle file found`)
- 낱말 하나만 자르기(`-st fragment`)는 낱말마다 시각이 적힌 자막이 필요해 **실패**했습니다
- 자동 받아쓰기(`--transcribe`)는 **영어 모델만** 들어 있어, 한국어 기계 음성을 영어 낱말로 받아썼습니다. 한국어 모델은 작업 공간에서 내려받기가 막혀 시연하지 못했습니다
- 장면이 많으면 영상 만들기가 오래 걸립니다 (48장면 148초)
- 2024년 4월 이후 새 버전이 없습니다

## 4. 설치와 사용 방법 (Windows)

**1) 파이썬 설치** — https://www.python.org/downloads/ 에서 받아 설치합니다. 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다.

**2) videogrep 설치** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 설치 (약 315MB, 영상 처리 도구 ffmpeg가 함께 설치됨 — 리눅스 기준)
pip install videogrep
:: 설치 확인 (videogrep 2.3.0 처럼 나오면 성공)
videogrep --version
```

**3) 영상과 자막 준비** — 같은 폴더에 `강의.mp4`와 `강의.srt`처럼 **이름이 똑같은** 두 파일을 둡니다.

**4) 장면 찾고 모으기**
```cmd
:: 영상이 있는 폴더로 이동 (예: D:\영상)
cd /d D:\영상
:: 찾기만 (찾은 자막 줄과 시각만 보여 줌)
videogrep -i 강의.mp4 -s 시험 --demo
:: 찾은 장면만 이어 붙여 저장 (-o 뒤에 저장할 이름)
videogrep -i 강의.mp4 -s 시험 -o 시험모음.mp4
:: 여러 낱말 중 하나라도 (따옴표로 감싸기)
videogrep -i 강의.mp4 -s "시험|중요" -o 복습.mp4
:: 앞뒤 0.5초 여유
videogrep -i 강의.mp4 -s 시험 -p 0.5 -o 시험모음.mp4
```

**5) 물어보는 대로 실행하는 파일** — 예제 파일 `장면모으기.bat`(아래 링크)을 영상 폴더에 넣고 두 번 누르면, 영상 이름과 낱말을 물어본 뒤 `모음_낱말.mp4`를 만듭니다. (Windows 실행 확인 전 파일)

## 5. 어디에 쓰면 좋을까

- **온라인 강의로 공부하는 분** — "시험", "중요"가 나온 장면만 모아 복습합니다
- **회의 녹화를 다시 봐야 하는 분** — "결정", "마감" 장면만 모아 결론을 확인합니다 (회사 업무라면 아래 라이선스 확인)
- **발표를 연습하는 분** — 말버릇만 모아 몇 번 했는지 확인합니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 개인과 이익을 추구하지 않는 단체는 무료로 쓸 수 있습니다. 다만 라이선스(Anti-Capitalist License)에 **이익을 내는 일반 회사·군대·경찰은 쓸 수 없다**고 적혀 있습니다. 회사에서 쓰기 전에 라이선스 원문을 확인하시기 바랍니다.

**Q. 자막이 없는 영상도 됩니까?**
A. 시연에서는 **0장면**이었습니다. 자동 받아쓰기 옵션이 있지만 들어 있는 모델이 영어용이라, 한국어 영상은 자막 파일을 먼저 준비해야 합니다.

**Q. 한국어 낱말로 찾을 수 있습니까?**
A. 네. 시연에서 '소금', '결정', '음,' 같은 한국어 낱말로 모두 찾았습니다.

**Q. 원본 영상이 바뀝니까?**
A. 시연에서는 원본은 그대로였고, `-o`로 정한 새 파일만 만들어졌습니다.

**Q. 유튜브 영상을 잘라 올려도 됩니까?**
A. 남이 만든 영상을 잘라 다시 올리면 저작권 문제가 생길 수 있습니다. 내가 만든 영상이나 쓸 권리가 있는 영상에만 쓰시기 바랍니다.
