▶ 설치와 사용 (cmd) — 영상과 이름이 같은 자막(.srt)이 필요합니다 (강의.mp4 + 강의.srt)
   pip install videogrep
   videogrep -i 강의.mp4 -s 시험 --demo          ← 찾기만
   videogrep -i 강의.mp4 -s 시험 -o 시험모음.mp4  ← 장면만 이어 붙여 저장
   videogrep -i 강의.mp4 -s "시험|중요" -o 복습.mp4 ← 여러 낱말
