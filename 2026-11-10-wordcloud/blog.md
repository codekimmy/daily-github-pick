## 1. wordcloud란 무엇입니까?

**wordcloud**(워드클라우드)는 글 속 낱말이 몇 번 나왔는지 세어, **많이 나온 낱말일수록 큰 글씨로** 빈자리에 채워 넣은 그림을 만드는 프로그램입니다. 이런 그림을 **낱말 구름**(word cloud)이라고 부릅니다.

2012년에 Andreas Mueller가 만들어 공개했고, GitHub에서 별 약 10,500개를 받았습니다. MIT 라이선스라 개인은 물론 회사에서도 무료로 쓸 수 있습니다.

명령어 한 줄로도, 파이썬 코드 몇 줄로도 쓸 수 있습니다. 모양 틀(하트·말풍선), 색 바꾸기, 빼고 싶은 말 정하기 같은 꾸미기 기능이 들어 있습니다.

## 2. 비유로 쉽게 이해하기

wordcloud는 **낱말들의 '인기투표 개표판'**입니다.

1. **한 표씩 세기** — 글에 낱말이 한 번 나올 때마다 그 낱말에 한 표를 줍니다
2. **큰 글씨로 붙이기** — 표를 많이 받은 낱말부터 큰 글씨로 판 위 빈자리에 붙이고, 표가 적은 낱말은 작은 글씨로 남은 틈에 넣습니다
3. **한국어는 표가 갈라짐** — '제주도에', '제주도는'처럼 조사가 붙으면 다른 후보로 쳐서 표가 흩어집니다. 그래서 개표 전에 조사를 떼어 주는 도우미(**형태소 분석기** — 낱말을 뜻 단위로 쪼개는 도구)를 함께 씁니다

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 자동으로 실행한 **시연 결과**입니다. 글 자료는 모두 **시연용으로 만든 가상 자료**(가상 '제주 여행 준비방' 단톡방 600줄, 가상 카페 손님 의견 150줄)입니다.

**아쉬운 점**
- 한글은 **글꼴 파일을 꼭 지정**해야 합니다 (안 하면 □□□)
- 조사를 떼려면 낱말 고르기 도구를 **따로 설치**해야 합니다 (202MB 추가)
- 낱말 고르기 도구도 가끔 잘못 나눕니다 ('일정표' → 일정 + 표)
- 낱말이 하나도 없는 글은 `ValueError` 오류로 멈춥니다
- 첫 설치 때 내려받기가 멈춰 5분이 넘게 걸렸고, 다시 시도해 10.5초에 설치됐습니다
- 크기는 **나온 횟수**일 뿐, 중요한 말이라는 뜻은 아닙니다

## 4. 설치와 사용 방법 (Windows)

**1) 파이썬 설치** — https://www.python.org/downloads/ 에서 받아 설치합니다. 첫 화면 아래 **'Add python.exe to PATH'에 꼭 체크**하시기 바랍니다.

**2) 설치** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 낱말 구름 프로그램 (약 137MB — 리눅스 기준)
pip install wordcloud
:: 한국어 조사를 떼어 줄 도구 (약 202MB)
pip install kiwipiepy
```

**3) 명령어 한 줄로 만들기** (글 파일은 UTF-8로 저장)
```cmd
:: 글 파일이 있는 폴더로 이동 (예: D:\글)
cd /d D:\글
:: 대화.txt → 구름.png (한글은 맑은 고딕 지정 필수)
wordcloud_cli --text 대화.txt --fontfile C:\Windows\Fonts\malgun.ttf --imagefile 구름.png
:: 하트 모양 틀(흑백 그림)과 흰 배경
wordcloud_cli --text 대화.txt --fontfile C:\Windows\Fonts\malgun.ttf --mask 하트.png --background white --imagefile 하트구름.png
```

**4) 조사를 떼고 명사만 — 예제 파일 `카톡구름.py`** (아래 링크)
```cmd
:: 카톡 '대화 내보내기' 파일 → 대화_낱말구름.png + 대화_낱말순위.csv
python 카톡구름.py 대화.txt
:: 빼고 싶은 말, 쪼개지면 안 되는 낱말, 모두 가로로
python 카톡구름.py 대화.txt --빼기 "생각,기대" --단어 "흑돼지" --가로
```
날짜·이름 부분을 떼고 말만 남긴 뒤 명사만 셉니다. 순위 파일은 엑셀에서 바로 열립니다.

**5) 물어보는 대로 실행하는 파일** — 예제 파일 `낱말구름.bat`을 `카톡구름.py`와 같은 폴더에 두고 두 번 누르면, 파일 이름과 뺄 말을 물어본 뒤 그림을 만듭니다. (Windows 실행 확인 전 파일)

## 5. 어디에 쓰면 좋을까

- **모임·동호회 총무** — 1년치 단톡방 대화를 그림 한 장으로 남깁니다 (공유 전 구성원 동의)
- **작은 가게 사장님** — 손님 의견에서 많이 나온 말(자리·가격 등)을 한눈에 봅니다
- **학생·발표자** — 설문 답변을 발표 자료용 그림으로 만듭니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. MIT 라이선스라 개인과 회사 모두 무료로 쓸 수 있습니다. 함께 쓰는 kiwipiepy도 무료 공개 프로그램(Apache-2.0)입니다.

**Q. 한글이 네모로 나옵니다.**
A. 글꼴을 지정하지 않았기 때문입니다. 명령어에는 `--fontfile C:\Windows\Fonts\malgun.ttf`를 붙이시기 바랍니다.

**Q. '제주도에', '제주도는'이 따로 나옵니다.**
A. wordcloud는 띄어쓰기로만 낱말을 나눕니다. 예제 `카톡구름.py`처럼 kiwipiepy로 명사만 골라 세면 하나로 모입니다.

**Q. 카톡 대화는 어떻게 꺼냅니까?**
A. 카카오톡 대화방 설정의 '대화 내보내기'로 글 파일을 받을 수 있습니다. 시연에서는 비슷한 모양의 가상 대화를 썼으며, 실제 내보내기 파일 모양은 기기·버전에 따라 다를 수 있습니다.

**Q. 원본 글 파일이 바뀝니까?**
A. 시연에서는 원본은 그대로였고, 새 그림·순위 파일만 만들어졌습니다.

- 다른 사람이 쓴 대화·설문으로 만든 그림은 개인정보가 드러날 수 있으므로 동의 없이 공유하지 마시기 바랍니다. 낱말 크기는 나온 횟수일 뿐이므로 해석에 주의하시기 바랍니다.
