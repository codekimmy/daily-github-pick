## 1. czkawka란 무엇입니까?

**czkawka**(츠카프카)는 폴더를 지정하면 그 안에서 **똑같은 파일, 비슷한 사진·영상, 빈 폴더, 큰 파일, 임시 파일, 위치 정보가 든 사진** 등을 찾아 목록으로 보여 주는 프로그램입니다. 원하면 찾은 파일을 휴지통으로 옮겨 줍니다. 이름은 폴란드어로 '딸꾹질'이라는 뜻입니다.

폴란드 개발자 Rafał Mikrut가 2020년에 공개했고, GitHub에서 별 약 3.5만 개를 받았습니다. 광고가 없고 인터넷에 접속하지 않는다고 제작자가 밝히고 있습니다. 명령어판은 MIT, 새 화면 프로그램 **Krokiet**(크로키에트)는 GPL-3.0 라이선스이며 둘 다 무료입니다.

## 2. 비유로 쉽게 이해하기

czkawka는 **파일 '지문' 감식반**입니다.

1. **내용으로 지문 뜨기** — 감식반은 파일마다 내용으로 지문을 뜹니다. **이름이 달라도 지문이 같으면 똑같은 파일**입니다
2. **크기가 같은 파일끼리만 대조** — 모든 파일에 지문을 뜨면 오래 걸리므로, 감식반은 크기가 같은 파일끼리 먼저 모아 놓고 대조합니다. 그래서 빠릅니다
3. **사진은 '닮은 정도'까지** — 사진은 조금만 고쳐도 지문이 달라지므로 감식반이 닮은 정도를 따로 비교합니다. 다만 기준을 너무 넓히면 다른 사진을 같은 사진으로 착각하기도 합니다

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 명령어판 `czkawka_cli` 12.0.2로 자동 실행한 **시연 결과**입니다. 폴더와 파일은 모두 **시연용으로 만든 가상 자료**(가상 'PC 정리 전' 폴더, 파일 41개 · 146.7MB)이고, 사진은 저작권 없는 예제 사진(고양이·커피 CC0, 로켓 퍼블릭 도메인)입니다. 화면 프로그램 Krokiet은 이번 시연에서 실행하지 않았습니다.

[이미지: cz-anim.gif | 대체 텍스트: 가상 PC 폴더 파일 카드 → 이름이 다른 보고서 4개가 한 묶음(복사본 79.7MB) → 고친 고양이 사진 6장 중 5장 찾음 → 빈 폴더·위치 정보 사진 개수 순으로 바뀌는 czkawka 과정 애니메이션]

**① 똑같은 파일** — 기본 설정으로 **0.19초** 만에 복사본 7개(79.68MB)를 찾았습니다. 강의자료.zip 3개, 설치 파일 2개, 영상 2개, 그리고 이름은 '영수증.pdf'인데 내용이 커피.jpg와 같은 파일이 한 묶음으로 나왔습니다. 기본 설정은 **8KB보다 작은 파일을 건너뛰어서** 보고서 4개가 빠졌고, `-m 1`을 붙이자 **10개 · 6묶음**이 됐습니다.

[이미지: 정리결과_요약.png | 대체 텍스트: 가상 PC 정리 전 폴더 41개 파일·146.7MB를 czkawka로 검사한 요약 카드, 똑같은 파일 10개·79.7MB, 비슷한 사진 15장, 빈 폴더 3개, 위치 정보 사진 4장 등 8가지 결과 그림]

**② 비슷한 사진** — 고양이 원본에 글자를 넣거나 크기·화질·밝기를 바꾼 사진 6장을 함께 넣은 결과, 설정에 따라 결과가 크게 달랐습니다.

| 설정 | 원본과 같은 묶음으로 찾은 사진 |
|---|---|
| 기본 (차이 5) | 글자 넣은 사진 1장 (밝게·흑백은 둘끼리 따로 묶음) |
| 차이 15 (`-s 15`) | 글자 · 크기 절반 · 화질 25 → 3장 |
| 차이 15 + 돌림 포함 | 6장 중 **5장** + 90° 돌린 로켓 사진 |

가장자리를 자른 사진은 끝내 찾지 못했고, 돌림 포함 설정에서는 **서로 다른 바다 그림 2장을 비슷한 사진으로 잘못 묶었습니다**. 묶음은 꼭 눈으로 확인하시기 바랍니다.

[이미지: 비슷한사진_비교.png | 대체 텍스트: czkawka 비슷한 사진 찾기 비교표, 고양이 원본과 고친 사진 6장·돌린 로켓·작게 줄인 커피 사진을 기본·차이 15·돌림 포함 설정별로 찾음과 못 찾음으로 표시한 결과 그림]

**③ 그 밖의 도구**

| 도구 | 결과 |
|---|---|
| 비슷한 영상 | 원본·복사본·크기만 줄인 영상(13.1MB ↔ 324KB) 3개 모두 한 묶음, 16.65초 (ffmpeg 필요) |
| 빈 폴더 · 빈 파일 | 3개 · 3개 (빈 폴더 안에 든 빈 폴더는 바깥 폴더 하나로) |
| 임시 파일 | .tmp · .crdownload · .bak 3개 (워드 임시 파일 `~$` 모양은 못 찾음) |
| 확장자가 틀린 파일 | 영수증.pdf(속은 JPG) · 로켓사진.jpg(속은 PNG) 2개 |
| 깨진 파일 | 망가진 압축 파일은 찾았지만, 앞부분만 남은 사진은 못 찾음 |
| 사진 속 위치 정보 | 4장 모두 찾음 → 원본은 두고 위치·날짜를 지운 새 사진 4장 생성 (그림은 원본과 같음) |
| 파일 5,000개 (약 1GB) | 복사본 1,000개를 0.29초에 찾음 |

**④ 지울 때 생긴 일** — '묶음마다 가장 최근 파일만 남기고 지우기'(`-D AEN`)를 미리 보기(`-Q`)로 확인하자, **사진 폴더의 원본 '커피.jpg'가 지울 목록에** 들어 있었습니다. 복사본이 더 최근에 만들어졌기 때문입니다. 원본 폴더를 기준 폴더(`-r`)로 정하자 원본 폴더 파일은 목록에서 빠졌고, 휴지통으로 보내기(`-y`)로 6개를 옮겨 폴더가 146.7MB → 133.3MB가 됐습니다.

[이미지: terminal.gif | 대체 텍스트: 명령 프롬프트에서 czkawka_cli로 똑같은 파일 10개·79.68MB, 비슷한 고양이 사진 6장, 빈 폴더 3개, 위치 정보가 든 사진 4장을 차례로 찾고 지우기 미리 보기를 하는 터미널 화면]

**아쉬운 점**
- 자동 지우기 규칙은 어느 폴더가 원본인지 모릅니다 → 미리 보기와 기준 폴더 지정이 필수입니다
- 기본 설정은 작은 파일(일반 8KB, 사진 16KB 미만)을 건너뜁니다
- 비슷한 사진은 자른 사진을 놓치고, 다른 그림을 묶기도 했습니다
- 명령어 결과는 영어로만 나옵니다
- 리눅스에서 소스로 설치하면 8분 18초가 걸렸습니다 (Windows는 내려받기만 하면 됨)

## 4. 설치와 사용 방법 (Windows)

> 아래 Windows 방법은 이번 시연에서 실행해 보지 않은 안내입니다(리눅스 시연).

**방법 1: 화면 프로그램 Krokiet** — https://github.com/qarmin/czkawka/releases 에서 최신 버전 **Assets**의 `windows_krokiet_on_windows_skia_opengl.exe`(12.0.1 기준 이름)를 내려받아 실행합니다. 설치 과정 없이 실행되는 파일입니다.

**방법 2: 명령어** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 설치 (Windows 10/11 기본 설치 도구 winget)
winget install --id qarmin.czkawka.cli -e
:: 다운로드 폴더의 똑같은 파일 찾기 (작은 파일 포함) → 결과를 글 파일로 (지우지 않음)
czkawka_cli dup -d "%USERPROFILE%\Downloads" -m 1 -f 똑같은파일.txt
:: 사진 폴더의 비슷한 사진 찾기 (차이 15, 돌린 사진 포함)
czkawka_cli image -d "%USERPROFILE%\Pictures" -s 15 --geometric-invariance mirror-flip-rotate90 -f 비슷한사진.txt
:: 빈 폴더 찾기
czkawka_cli empty-folders -d "%USERPROFILE%\Documents" -f 빈폴더.txt
```

**지울 때는 꼭 이 순서로**
```cmd
:: 1) 미리 보기 (-Q): 목록만 봅니다. -r 로 정한 원본 폴더 파일은 지울 목록에 들어가지 않습니다
czkawka_cli dup -d "%USERPROFILE%\Downloads" -r "%USERPROFILE%\Documents" -m 1 -D AEN -Q
:: 2) 목록이 맞으면 -Q 대신 -y : 휴지통으로 보냅니다
czkawka_cli dup -d "%USERPROFILE%\Downloads" -r "%USERPROFILE%\Documents" -m 1 -D AEN -y
```

**사진 위치 정보 지우기** (원본은 그대로, `이름.czkawka_cleaned_exif.jpg` 새 사진 생성)
```cmd
czkawka_cli exif-remover -d "%USERPROFILE%\Pictures\올릴사진" -F
```

**물어보는 대로 실행하는 파일** — 예제 파일 `정리점검.bat`을 마우스로 두 번 누르면 화면이 검사할 폴더를 물어본 뒤, 똑같은 파일·비슷한 사진·빈 폴더·큰 파일·위치 정보 사진 목록을 바탕화면에 글 파일로 만듭니다. 이 예제 파일은 아무것도 지우지 않습니다. (Windows 실행 확인 전 파일)

## 5. 어디에 쓰면 좋을까

- **저장 공간이 늘 모자란 사람** — 다운로드·바탕화면에 쌓인 복사본과 큰 파일을 찾습니다
- **휴대폰 사진을 PC에 모아 두는 사람** — 카톡으로 받아 크기만 줄어든 비슷한 사진을 골라냅니다
- **블로그·중고거래에 사진을 올리는 사람** — 올리기 전에 위치 정보를 지운 새 사진을 만듭니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. 명령어판은 MIT, 화면 프로그램 Krokiet은 GPL-3.0 라이선스이며 개인·회사 모두 무료로 쓸 수 있습니다. 광고도 없습니다.

**Q. 찾기만 해도 파일이 지워집니까?**
A. 아닙니다. 지우기 설정(`-D`)을 붙이지 않으면 목록만 보여 줍니다. 시연에서도 찾기만 한 명령은 파일을 바꾸지 않았습니다.

**Q. 실수로 원본을 지우면 어떻게 합니까?**
A. 휴지통으로 보내기(`-y`)를 쓰면 휴지통에서 되살릴 수 있습니다. 그래서 지울 때는 미리 보기(`-Q`) → 휴지통으로 보내기 순서를 권합니다. 중요한 파일은 먼저 백업하시기 바랍니다.

**Q. 비슷한 사진을 더 많이 찾고 싶습니다.**
A. 차이 값(`-s`, 0~40)을 키우면 더 많이 찾지만, 다른 사진을 잘못 묶을 수도 있습니다. 시연에서는 15에서 고친 사진을 대부분 찾았습니다.

**Q. 예전 Czkawka 화면 프로그램과 Krokiet은 무엇이 다릅니까?**
A. 제작자는 예전 화면 프로그램(Czkawka GTK)은 12.0이 마지막 버전이라고 밝히고, 새 화면 프로그램 Krokiet을 쓰라고 권합니다. 두 프로그램과 명령어판은 같은 엔진을 씁니다.
