# 명령 한 줄로 인사 글자에 불꽃놀이 효과, 무료 프로그램 terminaltexteffects 사용법 총정리 (효과 37가지·한글 주의점)

> **한 줄 요약** — 글자 두 줄을 파일에 적고 명령 한 줄을 입력하면, 명령 창 속 글자가 불꽃처럼 터지거나 암호가 풀리듯 나타나는 무료 프로그램입니다.
> ⭐ 별 약 4,300 · 오픈소스(누구나 무료로 쓰고 고칠 수 있게 공개된 프로그램) · MIT 라이선스 · 파이썬

> **일반인 쓸모 ★★★☆☆** — `pip install` 한 줄로 설치되고 명령도 짧지만, 파이썬을 먼저 설치해야 하고 결과를 영상으로 남기려면 화면 녹화가 따로 필요합니다. 쓸 일도 축하·발표 같은 때로 가끔입니다.
> **이걸로 할 수 있는 것**
> 1. 생일·새해 인사 글자가 **불꽃놀이처럼 터졌다가 내려앉는 화면**을 녹화해 단톡방 축하 영상으로 보낸다

> 3. 파이썬 예제로 **받는 사람 이름을 넣은 인사 카드 효과**를 만든다

## 1. terminaltexteffects란 무엇입니까?

**terminaltexteffects**(줄여서 **tte**, 터미널 텍스트 이펙트)는 명령 창(검은 글자 창)에 글을 보여 줄 때 **움직이는 효과**를 입히는 프로그램입니다. 불꽃놀이, 암호 해독, 불타기, 블랙홀, 물결 등 효과가 **37가지** 들어 있습니다.

개발자 ChrisBuilds가 2023년에 공개했고, GitHub에서 별 약 4,300개를 받았습니다. 라이선스는 MIT로 개인·회사 모두 무료입니다. 명령어로도 쓰고, 파이썬 코드 안에서도 불러 쓸 수 있습니다.

## 2. 비유로 쉽게 이해하기

tte는 **'글자 무대 연출가'**입니다.

1. **배우 = 글자 하나하나** — 연출가는 글의 글자 하나하나를 무대(명령 창) 위 배우로 세웁니다
2. **대본 = 움직일 길 + 바뀔 색** — 효과 37가지는 대본 37가지입니다. 대본마다 배우가 걸어올 길과 바뀔 색이 정해져 있습니다
3. **막이 내리면 원래 글** — 배우가 모두 제자리에 서면 원래 글이 완성됩니다
4. **무대 크기** — 무대 크기는 사용자가 정합니다. 다만 한글 배우는 몸집이 두 칸인데 연출가는 한 칸으로 계산해서, 무대가 너무 넓으면 배우가 자리를 잘못 잡기도 합니다

## 3. 실제 화면으로 보기

클라우드 작업 공간(리눅스, CPU 2개)에서 tte 0.15.0으로 자동 실행한 **시연 결과**입니다. 인사 글("생일 축하합니다! / 오늘도 좋은 하루 되세요")과 열 줄짜리 글은 **시연용으로 직접 쓴 글**입니다. 마지막 화면은 가로 80칸 가상 터미널에 실제 출력을 그대로 넣어 확인했습니다.

[이미지: tte-anim.gif | 대체 텍스트: 시연용 인사 글 두 줄 → 분홍·노랑 불꽃놀이 13.9초 → 암호 해독·불타기 효과 → 효과 37가지 중 25개 5초 안·한글 화면 36/37 순으로 바뀌는 terminaltexteffects 과정 애니메이션]

**① 같은 글, 효과 이름만 바꾸기** — `tte -i 인사.txt decrypt`처럼 글 파일 이름 뒤에 효과 이름을 붙입니다. 암호 해독은 엉뚱한 기호가 한 글자씩 진짜 글자로 바뀌며 **9.6초**, 불타기는 **5.0초**, 불꽃놀이는 **13.9초**가 걸렸습니다.

[이미지: 효과모음.png | 대체 텍스트: 같은 인사 글에 terminaltexteffects 효과 6가지(불꽃놀이·암호 해독·불타기·블랙홀·물결·격자)를 실행한 도중 모습을 나란히 놓은 결과 그림]

**② 효과 37가지 길이** — 같은 인사 글로 37가지를 모두 실행했습니다. 가장 짧은 효과는 **0.1초**(overflow), 가장 긴 효과는 **23.3초**(rings)였고, **25개가 5초 안**에 끝났습니다. 어느 효과가 알맞은지는 길이를 보고 직접 고르시기 바랍니다.

[이미지: 효과길이.png | 대체 텍스트: terminaltexteffects 효과 37가지가 끝날 때까지 걸리는 시간 막대그래프, 가장 짧은 overflow 0.1초·가장 긴 rings 23.3초·25개가 5초 안에 끝난 결과 그림]

**③ 한글은 무대 크기가 중요합니다** — 효과가 끝난 뒤 마지막 화면에 원래 글만 깨끗하게 남았는지 확인했습니다.

| 무대 설정 | 한글 인사 글 정상 |
|---|---|
| 기본 (무대 = 글 크기) | **36/37** (middleout은 끝 글자가 겹쳐 "되세요요") |
| 넓은 무대 `--canvas-width 40 --canvas-height 10 --anchor-text c` | **36/37** (unstable은 글자 조각이 남음) |
| 가로 전체 무대 `--canvas-width 0` | **13/37** |

영어 글은 기본 무대에서 37/37 모두 정상이었습니다. 또 글자가 움직이는 동안에는 한글이 섞인 줄이 오른쪽으로 밀려 보였습니다.

**아쉬운 점**
- 한글은 무대 크기에 따라 글자 조각이 남습니다 (가로 전체 무대 13/37)
- 글자가 움직이는 동안 한글 줄이 오른쪽으로 밀려 보입니다
- 영상 파일을 저장하는 기능이 없어 화면 녹화가 필요합니다
- 파이썬을 먼저 설치해야 하고, 도움말은 영어로만 나옵니다

## 4. 설치와 사용 방법 (Windows)

> 아래 Windows 방법은 이번 시연에서 실행해 보지 않은 안내입니다(리눅스 시연). 색이 잘 보이는 **터미널(Windows Terminal)** 창을 권합니다.

**1단계: 파이썬 설치** — python.org에서 파이썬을 내려받아 설치합니다. 설치 화면 아래쪽 **"Add python.exe to PATH"**를 꼭 체크하시기 바랍니다.

**2단계: tte 설치와 실행** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 설치
pip install terminaltexteffects
:: 설치 확인 → TerminalTextEffects 0.15.0
tte --version
:: 메모장이 열리면 인사 글 두 줄을 쓰고 저장
notepad 인사.txt
:: 암호 해독 효과
tte -i 인사.txt decrypt
:: 넓은 무대 + 생일 색 불꽃놀이
tte -i 인사.txt --canvas-width 40 --canvas-height 10 --anchor-text c fireworks --firework-colors ff6b9d ffd166 ffffff --final-gradient-stops ff6b9d ffd166
:: 효과 무작위로 하나
tte -i 인사.txt -R
:: 효과 37가지 이름 보기
tte -h
```

한글 글은 `echo`로 넘기면 깨질 수 있으므로 **메모장에 저장한 파일을 `-i`로 넘기는 방법**을 권합니다.

**예제 파일** — 예제 파일 `인사효과.bat`을 마우스로 두 번 누르면 화면이 인사 글 두 줄과 효과 번호(1 불꽃놀이 · 2 암호 해독 · 3 불타기 · 4 무작위)를 물어본 뒤 넓은 무대로 효과를 보여 줍니다(Windows 실행 확인 전). 파이썬 예제 `인사카드.py`는 받는 사람 이름을 물어본 뒤 "○○님 / 생일 축하합니다!"를 불꽃놀이로 보여 줍니다.

**영상으로 남기기** — Windows 11 **캡처 도구 → 녹화 → 명령 창 영역 선택** 뒤 tte 명령을 실행하고 녹화를 멈추면 mp4로 저장됩니다(Windows 실행 확인 전).

## 5. 어디에 쓰면 좋을까

- **가족·친구 축하** — 생일·새해 인사 글자 효과를 녹화해 단톡방에 보냅니다
- **발표·영상 인트로** — 첫 화면 제목이 암호 해독되듯 나타나게 만듭니다
- **명령 창 꾸미기** — 명령 창을 열 때 오늘의 다짐이 흩어졌다 모이게 합니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. MIT 라이선스로 개인·회사 모두 무료로 쓸 수 있습니다.

**Q. 한글도 됩니까?**
A. 됩니다. 시연에서 기본 무대와 넓은 무대(가로 40칸)는 37가지 중 36가지가 마지막에 한글을 깨끗하게 보여 줬습니다. 다만 가로 전체 무대에서는 13가지만 깨끗했으므로 무대를 가로 40칸 정도로 정하시기 바랍니다.

**Q. 영상 파일로 바로 저장됩니까?**
A. 아닙니다. tte는 명령 창에 효과를 보여 주기만 합니다. 캡처 도구 녹화 같은 화면 녹화 프로그램이 따로 필요합니다.

**Q. 효과가 너무 깁니다.**
A. 효과마다 길이가 0.1초에서 23.3초까지 다릅니다. 짧은 효과(5초 안에 끝나는 효과 25가지)로 바꾸거나 글을 짧게 줄이시기 바랍니다.

**Q. 실행할 때마다 모양이 다릅니다.**
A. 불꽃놀이·암호 해독처럼 무작위가 들어간 효과는 실행할 때마다 모양과 길이가 달라집니다. 녹화할 때는 여러 번 실행해 보고 고르시기 바랍니다.

## 마무리

terminaltexteffects는 명령 한 줄로 인사 글자에 불꽃놀이·암호 해독 같은 연출을 입히는 무료 프로그램입니다. 한글은 **무대를 가로 40칸 정도로 정하고, 녹화 전에 마지막 화면을 확인**하시기 바랍니다.
