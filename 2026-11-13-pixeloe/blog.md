# 내 사진을 게임 속 도트 그림으로, 무료 프로그램 PixelOE 사용법 총정리 (보통 모자이크와 비교·설치 주의점)

> **한 줄 요약** — 사진 파일 이름을 넣고 명령 한 줄을 입력하면, 사진이 작은 네모 점으로 이루어진 게임 속 그림(도트 그림)으로 바뀌는 무료 프로그램입니다. 보통 모자이크와 달리 눈·코 같은 테두리가 진한 점 줄로 남습니다.
> ⭐ 별 584 · 오픈소스(누구나 무료로 쓰고 고칠 수 있게 공개된 프로그램) · Apache-2.0 라이선스 · 파이썬

> **일반인 쓸모 ★★½☆☆ (2.5)** — 명령 한 줄로 사진이 도트 그림이 되고 AI 모델 내려받기도 없지만, 파이썬을 먼저 설치해야 하고 함께 설치되는 계산 도구(torch)가 커서 설치가 무겁습니다. 화면 프로그램 없이 명령어로만 쓰고, 사진을 도트 그림으로 바꿀 일도 프로필·취미 정도로 드뭅니다.
> **이걸로 할 수 있는 것**
> 1. 반려동물·음식 사진을 **옛날 게임 같은 도트 그림 프로필**로 바꾼다

## 1. PixelOE란 무엇입니까?

**PixelOE**(픽셀오이)는 사진을 **도트 그림**(픽셀 아트: 옛날 게임처럼 작은 네모 점으로 그린 그림)으로 바꿔 주는 프로그램입니다. 이름의 OE는 Outline Expansion, 우리말로 **'외곽선 넓히기'**입니다. 사진을 점으로 줄이기 전에 테두리 선을 먼저 굵게 만들어서, 작은 그림에서도 눈·코·그릇 테두리가 사라지지 않게 합니다.

개발자 KohakuBlueleaf가 2024년 3월에 공개했고, 2026년 9월에 1.0.0이 나왔습니다. GitHub 별은 584개, 라이선스는 Apache-2.0으로 개인·회사 모두 무료입니다. AI 모델이 아니라 계산 규칙으로 작동해서 **그래픽카드나 모델 내려받기가 필요 없습니다.**

## 2. 비유로 쉽게 이해하기

PixelOE는 사진을 작은 타일로 다시 붙이는 **'타일 장인'**입니다.

1. **타일 = 점 하나** — 장인은 사진을 바둑판처럼 칸으로 나누고, 칸 하나에 타일 한 장(색 하나)만 붙입니다. 칸 개수는 사용자가 정합니다
2. **먼저 윤곽선을 굵게** — 보통 모자이크는 칸 안 색을 평균 내서 가는 선이 주변 색에 섞여 사라집니다. 장인은 타일을 붙이기 전에 눈·코 테두리 같은 진한 선을 먼저 굵게 넓혀 둡니다
3. **칸마다 대표 색 고르기** — 칸 안의 밝고 어두운 차이를 보고 타일 색 하나를 고릅니다
4. **원래 사진 색에 다시 맞추기** — 색이 엉뚱하게 바뀌지 않게 마지막에 원래 사진 색 쪽으로 맞춥니다

- 화면 프로그램이 없고, 도움말은 영어로만 나옵니다

## 4. 설치와 사용 방법 (Windows)

> 아래 Windows 방법은 이번 시연에서 실행해 보지 않은 안내입니다(리눅스 시연). 설치 중에 torch(계산 도구)를 함께 내려받으므로 인터넷이 빠른 곳에서 설치하시기 바랍니다.

**1단계: 파이썬 설치** — python.org에서 파이썬 3.10 이상을 내려받아 설치합니다. 설치 화면 아래쪽 **"Add python.exe to PATH"**를 꼭 체크하시기 바랍니다.

**2단계: PixelOE 설치와 실행** — 명령 프롬프트(cmd)를 열고 입력합니다.
```cmd
:: 설치 (torch 등 함께 설치됨)
pip install pixeloe
:: 사진이 있는 폴더로 이동 (예: 바탕화면)
cd %USERPROFILE%\Desktop
:: 기본 설정으로 바꾸기
pixeloe.pixelize 고양이.png -O 고양이_도트.png
:: 큼직한 점 + 색 줄이기
pixeloe.pixelize 고양이.png -O 고양이_8색.png -S 64 -P 8 --colors 8
:: 결과 그림 열기
start 고양이_도트.png
```

설정은 `-S`(점 개수, 클수록 자세함), `-P`(점 하나 크기), `-T`(외곽선 두께), `--colors`(색 줄이기) 네 가지만 알면 됩니다. 결과 파일 이름(`-O`)을 꼭 정하시기 바랍니다. 원본 사진은 바뀌지 않습니다.

**예제 파일** — 예제 파일 `도트그림.bat` 위에 사진 파일을 마우스로 끌어다 놓으면, 화면이 도트 크기 번호(1 큼직한 점 · 2 보통 · 3 자세히)를 물어본 뒤 사진 옆에 `이름_도트128.png`처럼 새 파일을 만듭니다(Windows 실행 확인 전). 파이썬 예제 `도트변환.py`는 폴더 속 사진을 모두 바꾸고 '원본 | 보통 모자이크 | PixelOE' 비교 그림까지 만듭니다.

## 5. 어디에 쓰면 좋을까

- **SNS 프로필** — 반려동물·음식 사진을 도트 그림 프로필로 바꿉니다
- **도트 그림 게임·스티커·십자수** — 사진을 밑그림으로 바꾼 뒤 손으로 다듬습니다
- **모자이크 비교** — 보통 모자이크로 윤곽이 뭉개지던 사진을 같은 점 개수로 다시 바꿔 봅니다

## 6. 자주 묻는 질문

**Q. 무료입니까?**
A. 네. Apache-2.0 라이선스로 개인·회사 모두 무료로 쓸 수 있습니다.

**Q. 그래픽카드가 없어도 됩니까?**
A. 됩니다. 시연은 그래픽카드 없는 클라우드(CPU 2개)에서 했고, 기본 설정으로 사진 한 장에 2.5초가 걸렸습니다.

**Q. 인터넷에 사진이 올라갑니까?**
A. 아닙니다. 설치할 때만 인터넷이 필요하고, 사진을 바꾸는 계산은 내 PC 안에서 합니다.

**Q. 큰 사진은 오래 걸립니까?**
A. 시연에서는 가로 4000 화소 사진도 0.48초였습니다. 시간은 사진 크기보다 점 개수(`-S`)가 정합니다.

**Q. 색을 정확히 8가지로 만들 수 있습니까?**
A. `--colors 8`로는 정확히 8가지가 되지 않았습니다(시연 2,182가지). 정확한 색 수가 필요하면 그림 프로그램의 색 줄이기 기능으로 한 번 더 줄이시기 바랍니다.

## 마무리

PixelOE는 명령 한 줄로 사진을 외곽선 살린 도트 그림으로 바꾸는 무료 프로그램입니다. 설치가 무거운 편이므로 **인터넷이 빠른 곳에서 설치하고, 원본 사진은 따로 보관**하시기 바랍니다.
