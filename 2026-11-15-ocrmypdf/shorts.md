# 숏폼: 스캔 PDF, Ctrl+F가 안 됩니다 (51.9초, 세로 9:16)

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
스캔한 PDF는 Ctrl+F가 안 됩니다 — 무료 OCRmyPDF로 3쪽 2초 만에 해결
```

**설명란**
```
스캔한 PDF 속 글자는 사실 그림이라 Ctrl+F로 찾을 수 없습니다. 무료 프로그램 OCRmyPDF(오씨알마이피디에프)는 그림 위에 투명한 글자를 한 겹 덮어 찾기·복사가 되게 합니다!
시연 결과, 가상 스캔 3쪽(관리비 고지서·가정통신문·영수증)을 2.05초 만에 처리해 낱말 9개를 모두 찾았습니다. 언어를 정하지 않으면 한글이 엉뚱한 영어 글자로 바뀌었고, 거꾸로 넣은 쪽은 --rotate-pages로 바로 세워 100% 읽었습니다. 다만 표 안 글자는 일부 틀렸습니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 글자 인식은 틀릴 수 있으니 금액·날짜는 원본과 비교하시고, 원본 PDF는 따로 보관하시기 바랍니다.

#ocrmypdf #스캔PDF #PDF검색 #무료프로그램 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 Tesseract(글자 인식 프로그램) → 한국어 언어 파일 → OCRmyPDF 순서로 설치합니다. 명령은 ocrmypdf -l kor+eng --tesseract-pagesegmode 4 스캔본.pdf 검색가능.pdf 입니다. -l kor+eng 를 빼면 한글이 깨지니 꼭 넣으시기 바랍니다. 설치 명령과 PDF를 끌어다 놓기만 하면 되는 배치 파일(검색PDF만들기.bat)은 전체 영상 설명란 링크에 올려 두었습니다!
```
