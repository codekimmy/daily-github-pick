**설명란** (통째로 복사)
```
스캔한 PDF는 글자가 그림이라 Ctrl+F로 찾거나 복사할 수 없습니다. 무료 프로그램 OCRmyPDF(오씨알마이피디에프)는 그림 속 글자를 읽어 같은 자리에 투명한 글자를 붙여, 겉모습은 그대로 두고 찾기·복사가 되는 PDF를 만듭니다. Windows 설치 방법, 한국어 설정, 언어·읽는 방식에 따른 정확도 비교, 거꾸로·기울어진 쪽 바로잡기, 30쪽 처리 시간까지 클라우드 시연 결과로 보여 드립니다.

▶ Windows 배치 파일(검색PDF만들기.bat)·명령어 모음: https://github.com/codekimmy/daily-github-pick/tree/main/2026-11-15-ocrmypdf
▶ 명령어 (cmd, 관리자 권한) — 공식 설치 문서 기준
   winget install -e --id tesseract-ocr.tesseract
   curl -L -o "C:\Program Files\Tesseract-OCR\tessdata\kor.traineddata" https://github.com/tesseract-ocr/tessdata_fast/raw/main/kor.traineddata
   winget install -e --id astral-sh.uv
   uv tool install ocrmypdf
   ocrmypdf -l kor+eng --tesseract-pagesegmode 4 스캔본.pdf 검색가능.pdf
   (--rotate-pages 거꾸로 된 쪽 바로 세우기 · --deskew 기울기 바로잡기 · --skip-text 글자가 있는 쪽 건너뛰기)
※ 영상 속 문서는 직접 만든 가상 고지서·가정통신문·영수증이고, 글자 상자·숫자는 프로그램이 만든 실제 결과입니다.
※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-15 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- OCRmyPDF 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 중요한 파일은 백업 후 사용하시기 바랍니다.
- 글자 인식은 틀릴 수 있으니 금액·날짜·계좌번호는 원본과 비교하시고, 원본 PDF는 따로 보관하시기 바랍니다.
```
