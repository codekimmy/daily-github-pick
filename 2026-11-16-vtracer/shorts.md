# 숏폼: 작은 로고, 키우면 흐릿해집니다 (49.8초, 세로 9:16)

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
작은 로고 그림, 키우면 흐릿합니다 — 무료 VTracer로 0.06초 만에 SVG로
```

**설명란**
```
작은 로고 그림(JPG)을 크게 키우면 테두리가 흐릿하게 뭉개집니다. 무료 프로그램 VTracer(브이트레이서)는 그림을 확대해도 깨지지 않는 SVG로 바꿉니다!
시연 결과, 240px 가상 로고를 0.06초 만에 바꿔 20배로 키워도 테두리가 또렷했습니다. 그림자 진 서명 사진은 밝기 맞춤 옵션으로 획만 남겼고(정답 획과 겹친 정도 60.5% → 82.6%, 100%면 똑같음), 도트 그림은 pixel 모드로 칸 모양을 그대로 살렸습니다. 다만 사진은 SVG 파일이 원본보다 커졌습니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 원본 그림은 따로 보관하시고, 남이 만든 로고·그림은 권리를 확인한 뒤 쓰시기 바랍니다.

#vtracer #SVG변환 #로고확대 #무료프로그램 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 파이썬을 설치한 뒤 pip install vtracer==1.0.0a4 로 설치합니다. 판 번호를 빼면 옛 판이 설치되니 꼭 붙이시기 바랍니다. 로고는 max_colors=6, 서명은 clustering='bw', adaptive=True, 도트 그림은 mode='pixel' 설정을 씁니다. 그림을 끌어다 놓기만 하면 되는 배치 파일(SVG만들기.bat)은 전체 영상 설명란 링크에 올려 두었습니다!
```
