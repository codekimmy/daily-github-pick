작은 로고 그림(JPG·PNG)을 크게 키우면 테두리가 흐릿하게 뭉개집니다. 무료 프로그램 VTracer(브이티레이서)는 그림 속 색 덩어리의 테두리를 곡선으로 따라 그려, 확대해도 깨지지 않는 SVG 파일로 바꿉니다. Windows 설치 방법, 작은 로고 20배 확대 비교, 그림자 진 서명 사진에서 획만 남기기, 도트 그림 칸 모양 살리기, 사진 설정 5가지 비교까지 클라우드 시연 결과로 보여 드립니다.

▶ 명령어 (cmd) — 공식 안내 기준
   winget install -e --id Python.Python.3.12
   pip install vtracer==1.0.0a4   (버전 번호를 빼면 옛 버전 0.6.15가 설치됨)
   python -c "import vtracer; vtracer.Config(max_colors=6, simplify=1.5).convert_file('로고.jpg', '로고.svg')"
   (서명: clustering='bw', adaptive=True · 도트 그림: mode='pixel', filter_speckle=0)
※ 읽는 법: '같은 색 비율'은 원본 그림과 색이 거의 같은 점의 비율, '겹친 정도'는 서명에서 검게 그린 자리와 정답 획이 겹치는 비율입니다(100%면 똑같음). 로고는 같은 색 비율이 92.2%·93.0%로 비슷하고, 차이는 테두리가 흐릿한지 또렷한지에서 납니다. 일반 확대의 '색 189,744가지'는 눈에는 비슷해 보이는 미세하게 다른 중간색까지 센 값입니다(원본 로고는 4가지 색).
※ 영상 속 로고·서명·도트 그림은 직접 만든 가상 자료, 고양이 사진은 CC0 사진이고, SVG·숫자는 프로그램이 만든 실제 결과입니다.
※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-16 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- VTracer 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 중요한 파일은 백업 후 사용하시기 바랍니다.
- 원본 그림은 따로 보관하고 결과는 직접 확대해 확인하시기 바랍니다. 남이 만든 로고·그림은 권리를 확인한 뒤 쓰시기 바랍니다.
