**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

```

```

**설명란**
```
같은 노을 영상으로 GIF 움짤을 만들었는데, 흔한 변환은 5.2MB, 무료 프로그램 gifski(기프스키)는 1.4MB였습니다! gifski는 장면마다 색을 새로 골라 칠해서, 확대해도 하늘에 점무늬가 없었습니다(클라우드 시연 결과).
단, 메모장 같은 화면 녹화는 ffmpeg 팔레트 방법이 58KB로 gifski(98KB)보다 작았습니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 원본 영상은 지우지 말고 보관하고, 남의 영상으로 만든 움짤은 저작권을 먼저 확인하시기 바랍니다.

#gifski #움짤만들기 #GIF #무료프로그램 #shorts
```

```
Windows는 명령 프롬프트에 winget install --id ImageOptim.gifski -e 를 붙여넣으면 화면 프로그램이 설치되고, 영상을 창에 끌어다 놓아 GIF를 만듭니다(공식 안내 기준). 용량은 가로 크기와 초당 장면 수를 먼저 줄이면 가장 많이 줄어듭니다!
```
