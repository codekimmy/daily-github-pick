회의 녹음은 너무 작고 음악은 너무 큰 파일들, 소리 크기를 한 번에 맞춰 주는 무료 명령어 도구 ffmpeg-normalize(에프에프엠펙 노멀라이즈)를 소개합니다.
가상 녹음 4개를 한꺼번에 맞추기, 귀 기준(LUFS)과 최고점 맞추기 비교, mp3로 받기, 영상은 그림 그대로 소리만 키우기, 60분 녹음까지 클라우드 시연 결과로 보여 드립니다.

▶ 원본 저장소: https://github.com/slhck/ffmpeg-normalize
▶ 명령어·시연 코드: https://github.com/codekimmy/daily-github-pick/tree/main/2026-11-22-ffmpeg-normalize
▶ 명령어 (cmd) — 도움말 기준, Windows 실행은 시연하지 않음 (파이썬 3.10 이상 + ffmpeg 필요)
   winget install Gyan.FFmpeg        (ffmpeg 설치 예시)
   pip install ffmpeg-normalize        (설치)
   ffmpeg-normalize 파일1.wav 파일2.mp3        (여러 파일 맞추기 → normalized 폴더)
   ffmpeg-normalize 파일.wav -c:a libmp3lame -b:a 192k -ext mp3        (mp3로 받기)
   ffmpeg-normalize 영상.mp4 -c:a aac -b:a 128k -ar 48000 -ext mp4        (영상 소리만)
   ffmpeg-normalize 파일.wav -t -14        (목표 -14 LUFS)
▶ 명령어 없이 쓰기: 저장소 폴더의 demo/tools_win/소리크기맞추기.bat 위에 파일을 끌어다 놓으면 원본 옆 '소리맞춤' 폴더에 결과가 생깁니다 (설치 1~3단계 먼저)
▶ Windows 설치·실행·오류 해결 전체 순서는 위 저장소 링크의 README 'Windows에서 쓰는 법'에 있습니다
※ 읽는 법: LUFS(러프스)는 사람 귀가 느끼는 소리 크기 단위입니다. 0에 가까울수록 큰 소리이고 마이너스는 값에 붙는 부호입니다. 바뀐 크기 = 두 값의 차이입니다(-42.1 → -23.1 LUFS = 약 19 만큼 커짐).
※ 영상 속 소리 파일은 시연용으로 직접 합성한 가상 녹음이며, 숫자는 시연 측정값입니다.

※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-22 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- ffmpeg-normalize·ffmpeg 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 공식 저장소에서만 받으시기 바랍니다.
- 소리 파일을 바꿀 때는 원본을 따로 보관하고, 결과 파일을 직접 들어 확인하시기 바랍니다.
