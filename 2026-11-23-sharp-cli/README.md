# sharp-cli — 휴대폰 사진 여러 장의 용량을 명령 한 줄로 줄여 주는 무료 '사진 진공 압축팩'

> 📅 2026-11-23 · ⭐ 속 엔진 sharp 약 3.3만 (GitHub 검색 API 32,867, 2026-11-23 확인) · 명령어 도구 sharp-cli 229 · 🍴 sharp 1,453 · 📜 sharp Apache-2.0 · sharp-cli MIT (둘 다 상업적 사용 가능) · 💻 JavaScript(Node.js) + C++(libvips) · 🔖 sharp-cli 6.1.0 (npm, 2026-09-01, 안에 sharp 0.35.4) · Node.js 20.10 이상
> 🔗 https://github.com/lovell/sharp · https://github.com/vseventer/sharp-cli · npm https://www.npmjs.com/package/sharp-cli

> **일반인 쓸모 ★★★½☆ (3.5)** — 명령 한 줄로 휴대폰 크기 가상 사진 6장(16.5MB)이 약 0.5초 만에 1.64MB가 됐고, 사진 속 위치 정보도 기본으로 빠졌습니다. 블로그·서류 제출처럼 쓸 일은 자주 있지만, Node.js를 따로 설치해야 하는 명령어 도구이고 아이폰 HEIC 사진을 읽지 못해 별 세 개 반입니다.
> **이걸로 할 수 있는 것**
> 1. 블로그·카페에 올릴 **사진 여러 장을 한 번에 줄인다** (시연: 6장 16.5MB → 1.64MB, 약 0.5초)
> 2. 용량 제한이 있는 **서류 제출·메일 첨부 전에** 사진 크기를 줄인다 (시연: 60장 165MB → 10.1MB, 7.53초)
> 3. 사진을 공유하기 전에 **위치 정보(GPS)를 지운다** (시연: 기본 실행 결과에 위치 정보 없음)

## 한 줄 요약
사진 파일 여러 장을 정해 준 크기·화질·형식(JPG·WebP·AVIF 등)으로 줄여 새 파일로 저장해 주는 무료 명령어 도구입니다. 실제 그림 처리는 속 엔진 sharp(샤프, Node.js용 그림 처리 프로그램)가 맡고, sharp-cli(샤프 씨엘아이)는 명령 프롬프트에서 sharp를 부르는 껍데기입니다.

## 비유로 이해하기
sharp-cli는 **사진 진공 압축팩**입니다.

- **① 접기 = 크기 줄이기** — 4032 × 3024처럼 큰 휴대폰 사진을 가로 1600처럼 작게 접습니다 (`resize 1600`)
- **② 공기 빼기 = 화질 값** — 1~100 사이 화질 값으로 공기를 얼마나 뺄지 정합니다. 기본은 80이고, 너무 세게 빼면 잔무늬가 뭉개집니다 (`-q`)
- **③ 영수증 빼기 = 위치 정보 삭제** — 넣기 전에 주머니 속 영수증(촬영 위치·기기 정보)을 빼 둡니다. **기본으로 빠지고**, 남기려면 `-m`
- **압축팩은 새 상자에** — 결과 폴더를 따로 정하면 원본은 그대로 남습니다. 단, 결과 폴더를 원본 폴더로 정하면 **묻지 않고 원본을 덮어씁니다**(아래 시연 ⑨)

## 왜 뜨고 있나
- 속 엔진 sharp는 별 약 3.3만 개의 오래된 인기 프로젝트로, 저장소 마지막 업데이트는 2026-11-16입니다(GitHub 검색 API 기준). sharp-cli는 2026-08~09월에 6.0.0·6.1.0이 연달아 나왔습니다(npm 기록)
- 오늘 GitHub 인기 목록(최근 한 달 새 저장소, 검색 API) 후보는 AI 에이전트·에뮬레이터·개발 도구가 대부분이라 작업 공간에서 결과를 만들 수 없거나 개발자용이었고, 미리 실행해 본 예비 후보(`CANDIDATES.md`)에서 골랐습니다. 직전(소리·영상)과 겹치지 않는 사진 분야입니다

## Windows에서 쓰는 법 (처음부터 끝까지)
> 시연은 클라우드(리눅스)에서 했고, 아래 Windows 방법은 sharp-cli 도움말(`sharp --help`)·npm 패키지 정보(sharp에 Windows용 `@img/sharp-win32-x64` 설치 파일이 함께 올라와 있음)·winget 목록(`OpenJS.NodeJS.LTS`)을 바탕으로 정리한 것입니다. **Windows에서 직접 실행해 확인한 것은 아닙니다.** 각 단계의 '성공 화면'과 다르게 나오면 맨 아래 '자주 나는 오류'를 보시기 바랍니다.

### 0. 준비물
| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10·11 (64비트). 2단계 winget이 없으면 nodejs.org에서 설치 파일을 받음 |
| Node.js | 20.10 이상 (LTS 버전 권장, nodejs.org에서 무료) — npm(Node.js용 설치 도구)이 함께 설치됨 |
| sharp-cli | `npm install -g sharp-cli` 한 줄 (함께 설치되는 프로그램 32개, 시연 기준 약 38MB) |
| 따로 설치할 프로그램 | 없음 (그림 처리 프로그램 libvips가 sharp 안에 들어 있음) |
| 화면 | 없음 — 명령 프롬프트(cmd)에 글자로 명령을 입력, 또는 아래 5단계 `.bat` 파일에 사진을 끌어다 놓기 |

### 1. Node.js 설치
1. https://nodejs.org 에서 **LTS** 버전 설치 파일(Windows Installer, .msi)을 받아 실행합니다
2. 설치 화면은 **Next**를 눌러 기본값 그대로 진행합니다 ('Add to PATH' 항목이 기본으로 켜져 있음)
3. 설치가 끝나면 키보드 `윈도우 키` → `cmd` 입력 → **명령 프롬프트**를 **새로** 엽니다

```cmd
:: (1번 대신) winget(Windows 기본 설치 도구)으로 설치해도 됩니다 → 설치 동의를 물으면 Y
winget install OpenJS.NodeJS.LTS
:: 설치 뒤 명령 프롬프트 창을 닫고 새로 열어 확인 → "v22.x.x"처럼 v20.10 이상 숫자가 나오면 성공
node --version
```

### 2. sharp-cli 설치
```cmd
:: 설치(-g = 어느 폴더에서나 쓰게) → "added 32 packages"처럼 나오면 성공 (숫자는 버전에 따라 다를 수 있음)
npm install -g sharp-cli
:: 확인 → "6.1.0"처럼 버전 번호가 나오면 성공
sharp --version
```

### 3. 내 사진으로 해 보기 (명령 프롬프트)
1. 파일 탐색기에서 사진이 있는 폴더를 엽니다
2. 탐색기 위쪽 **주소창을 누르고 `cmd`를 입력한 뒤 Enter** → 그 폴더 위치에서 명령 프롬프트가 열립니다
3. 아래 명령 중 필요한 것을 입력합니다 (파일 이름에 띄어쓰기가 있으면 `"여행 사진.jpg"`처럼 큰따옴표로 감쌉니다)

```cmd
:: ① 폴더 안 jpg 사진을 모두 가로 1600으로 줄여 "작게" 폴더에 저장 (화질 80, 원본은 그대로)
sharp -i "*.jpg" -o "작게/{name}.jpg" --autoOrient resize 1600 1600 --fit inside --withoutEnlargement

:: ② 더 작게: WebP 형식으로 (일부 프로그램은 WebP를 열지 못함)
sharp -i "*.jpg" -o "작게/{name}.webp" --autoOrient resize 1600 1600 --fit inside

:: ③ 화질 값을 바꿔 용량 조절 (1~100, 숫자가 작을수록 작고 화질이 떨어짐)
sharp -i "*.jpg" -o "작게/{name}.jpg" -q 60 --autoOrient resize 1600 1600 --fit inside

:: ④ 사진 한 장만 인스타그램용 정사각형(가운데를 잘라 1080 × 1080)
sharp -i "여행 사진.jpg" -o "정사각형/{name}.jpg" --autoOrient resize 1080 1080

:: ⑤ 위치 정보 등 사진 정보를 남기고 싶을 때 (-m)
sharp -i "*.jpg" -o "작게/{name}.jpg" -m --autoOrient resize 1600 1600 --fit inside

:: ⑥ 결과 폴더 열기
explorer 작게
```
- 결과는 **명령을 실행한 폴더 안 `작게` 폴더**에 원래 이름(`{name}`) + 정한 확장자로 생깁니다. `{name}`은 sharp-cli가 원래 파일 이름으로 바꿔 넣는 틀입니다
- `--autoOrient`는 세로로 찍은 사진이 눕지 않게 바로 세우고, `resize 1600 1600 --fit inside`는 **긴 변을 1600**에 맞춥니다(가로 사진 1600 × 1200, 세로 사진 1200 × 1600). `--withoutEnlargement`는 원래 작은 사진을 키우지 않게 합니다
- **결과 폴더(`-o`)를 원본 폴더로 정하지 않습니다.** 시연에서 원본 폴더로 정하자 묻지 않고 원본 사진을 덮어썼습니다
- 같은 명령을 다시 실행하면 `작게` 폴더 안 같은 이름 파일을 묻지 않고 새로 덮어씁니다

### 4. 명령어 없이 쓰기 — 끌어다 놓는 실행 파일
저장소의 [`demo/tools_win/사진작게.bat`](demo/tools_win/사진작게.bat)을 내려받아 바탕화면 등에 두고, **사진 파일을 이 파일 위에 마우스로 끌어다 놓으면** 원본 옆 `작게만든사진` 폴더에 줄인 사진이 생깁니다(원본은 그대로).
- 기본 설정: 긴 변 1600, 화질 80, JPG, 세로 사진 바로 세우기, 작은 사진은 키우지 않음, 위치 정보 삭제
- 설정을 바꾸려면 `.bat`을 메모장으로 열어 `set SIZE=1600`(인스타그램용 1080), `set QUALITY=80`, `set FORMAT=jpg`(또는 webp)를 고칩니다
- 여러 장을 한꺼번에 끌어다 놓아도 됩니다. 1~2단계 설치가 먼저 끝나 있어야 하며, sharp가 없으면 무엇을 설치해야 하는지 화면에 안내합니다
- `.bat` 안 명령(`sharp -i 파일 -o "작게만든사진/{name}.jpg" -q 80 --autoOrient resize 1600 1600 --fit inside --withoutEnlargement`)은 리눅스에서 같은 옵션으로 확인했고(가로 사진 1600 × 1200, 세로 사진 1200 × 1600), `.bat` 파일 자체는 Windows에서 실행해 보지 않았습니다

### 5. 자주 나는 오류와 해결
| 화면에 나온 말 | 원인 | 해결 |
|---|---|---|
| `'node'은(는) 내부 또는 외부 명령 … 아닙니다` | Node.js 미설치 또는 설치 뒤 창을 새로 열지 않음 | 1단계 설치 후 **명령 프롬프트를 닫고 새로 열기** |
| `'sharp'은(는) 내부 또는 외부 명령 … 아닙니다` | sharp-cli 미설치 또는 창을 새로 열지 않음 | `npm install -g sharp-cli` 후 창을 새로 열기. 그래도 안 되면 PC를 다시 시작한 뒤 `sharp --version`으로 확인 |
| `No input files` (시연에서 본 문구) | 입력한 이름의 사진이 없음, 또는 파일 이름에 `[ ]`가 있음 | 명령 프롬프트가 사진 폴더에서 열렸는지 확인(`dir`), 파일 이름에서 대괄호 빼기 |
| `heif: … Support for this compression format has not been built in` (시연에서 본 문구) | 아이폰 HEIC 사진 | 아이폰 설정 › 카메라 › 포맷을 '높은 호환성'으로 바꾸면 JPG로 찍힘(이미 찍은 사진은 사진 앱 공유·내보내기 등으로 JPG로 바꾼 뒤 사용) |
| `Expected integer between 1 and 100 for quality` (시연에서 본 문구) | 화질 값이 1~100 밖 | `-q 80`처럼 1~100 사이 숫자 |
| 결과 폴더 대신 확장자 없는 파일 하나가 생김 | `-o 작게`처럼 없는 폴더 이름만 씀 (사진 1장일 때) | `-o "작게/{name}.jpg"`처럼 `{name}` 틀 사용 |
| 결과 사진이 옆으로 누움 | 세로 사진의 방향 표시가 지워짐 | `--autoOrient` 붙이기 |
| 원본 사진이 작아짐 | 결과 폴더를 원본 폴더로 정함 | 결과는 항상 다른 폴더로(`작게/{name}.jpg`), 작업 전 원본 백업 |

### 6. 지우는 법
```cmd
:: sharp-cli 지우기
npm uninstall -g sharp-cli
:: Node.js 지우기 (winget으로 설치했을 때. 설치 파일로 설치했으면 설정 › 앱에서 제거)
winget uninstall OpenJS.NodeJS.LTS
```

### 자주 쓰는 옵션
`-i`(입력, `"*.jpg"`처럼 여러 장) · `-o`(결과, `"폴더/{name}.jpg"`) · `-q`(화질 1~100, 기본 80) · `-f`(형식: jpeg·webp·avif·png) · `-m`(사진 정보 유지) · `--autoOrient`(방향 바로잡기) · `resize 가로 세로`(크기) · `--fit inside`(비율 유지) · `--withoutEnlargement`(키우지 않기) · `--position attention`(정사각형으로 자를 때 눈에 띄는 곳 남기기) · `-n`(미리 해 보기, 저장하지 않음) · `rotate 90` · `greyscale`(흑백)

## 이런 사람에게 쓸모 있다
- **블로그·카페에 사진을 자주 올리는 사람** → 여러 장을 한 번에 같은 크기로 줄입니다
- **사진을 서류로 제출하거나 메일로 보내는 사람** → 용량 제한에 맞게 화질 값을 낮춥니다
- **사진을 공유하기 전에 위치 정보가 걱정되는 사람** → 기본 실행만으로 위치 정보가 빠집니다(결과는 사진 속성에서 직접 확인)

## 주의할 점
- **화면 없는 명령어 도구**이고, **Node.js를 따로 설치**해야 합니다
- 결과 폴더를 원본 폴더로 정하면 **묻지 않고 원본을 덮어씁니다.** 결과는 항상 다른 폴더로 받습니다
- **아이폰 HEIC 사진은 읽지 못했습니다**(시연 오류). JPG로 바꾼 뒤 써야 합니다
- 세로로 찍은 사진은 `--autoOrient`를 붙이지 않으면 결과가 옆으로 눕습니다
- PNG로 저장하면 사진은 오히려 커집니다(시연 16.5MB → 23.3MB). AVIF는 가장 작지만 가장 느리고(11.9초), 일부 프로그램은 열지 못합니다
- 화질 값을 너무 낮추면 잔무늬가 뭉개집니다. 시연 숫자는 컴퓨터가 그린 가상 사진 기준이며, 실제 사진은 줄어드는 비율이 다를 수 있습니다
