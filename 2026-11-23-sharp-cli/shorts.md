```

세로 사진은 --autoOrient 옵션을 붙여야 눕지 않습니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 사진을 바꿀 때는 원본을 따로 보관하고, 결과는 다른 폴더로 받아 화질을 직접 확인하시기 바랍니다.

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 Node.js(nodejs.org, LTS)를 설치한 뒤 명령 프롬프트에 npm install -g sharp-cli 를 붙여넣어 설치합니다. 그다음 사진 폴더에서 sharp -i "*.jpg" -o "작게/{name}.jpg" --autoOrient resize 1600 1600 --fit inside 를 입력하면 작게 폴더에 결과가 생깁니다. 사진을 끌어다 놓아 쓰는 실행 파일(.bat)과 오류 해결법은 롱폼 설명란의 저장소 링크에 있습니다!
