▶ 원본 저장소: https://github.com/lovell/sharp (속 엔진) · https://github.com/vseventer/sharp-cli (명령어 도구)
▶ 명령어·시연 코드: https://github.com/codekimmy/daily-github-pick/tree/main/2026-11-23-sharp-cli
▶ 명령어 (cmd) — 도움말 기준, Windows 실행은 시연하지 않음 (Node.js 20.10 이상 필요)
   winget install OpenJS.NodeJS.LTS        (Node.js 설치 예시)
   npm install -g sharp-cli        (설치)
   sharp -i "*.jpg" -o "작게/{name}.jpg" --autoOrient resize 1600 1600 --fit inside --withoutEnlargement        (폴더 사진 모두 긴 변 1600으로 → 작게 폴더)
   sharp -i "*.jpg" -o "작게/{name}.webp" --autoOrient resize 1600 1600 --fit inside        (WebP로 더 작게)
   sharp -i "*.jpg" -o "작게/{name}.jpg" -q 60 --autoOrient resize 1600 1600 --fit inside        (화질 값 60)
▶ 명령어 없이 쓰기: 저장소 폴더의 demo/tools_win/사진작게.bat 위에 사진을 끌어다 놓으면 원본 옆 '작게만든사진' 폴더에 결과가 생깁니다 (Node.js·sharp-cli 설치 먼저)
▶ Windows 설치·실행·오류 해결 전체 순서는 위 저장소 링크의 README 'Windows에서 쓰는 법'에 있습니다
※ 읽는 법: '닮은 정도(SSIM)'는 결과 사진이 원본과 얼마나 닮았는지를 0~1로 잰 값으로, 1이면 똑같고 작을수록 달라진 것입니다. 보기 좋은지는 직접 보고 고르시기 바랍니다.
※ 영상 속 사진은 시연용으로 컴퓨터가 그린 가상 사진이며, 숫자는 시연 측정값입니다. 실제 휴대폰 사진은 줄어드는 비율이 다를 수 있습니다.

※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-23 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- sharp·sharp-cli 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 공식 저장소에서만 받으시기 바랍니다.
- 사진을 바꿀 때는 원본을 따로 보관하고, 결과는 원본과 다른 폴더로 받아 화질을 직접 확인하시기 바랍니다.
