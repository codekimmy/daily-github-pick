# 숏폼: 와이파이 비밀번호, 아직도 불러 주십니까? (46.4초, 세로 9:16)

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
와이파이 비밀번호를 QR 한 장으로, 명령 한 줄 0.06초 — 무료 도구 segno
```

**설명란**
```
무료 명령어 도구 segno가 가상 와이파이 QR을 0.06초 만에 만들었고, 안드로이드 휴대폰 QR 앱으로 읽으니 이름·비밀번호가 그대로 나왔습니다(실제 와이파이 접속은 가상 와이파이라 확인 못 함). 가운데를 10% 가리면 여분 칸이 가장 많은 H 단계만 읽혔습니다.
읽는 법: '10% 가림'은 흰 여백까지 포함한 그림 전체 넓이 기준입니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 와이파이 QR에는 비밀번호가 그대로 들어가므로 아는 사람에게만 보여 주고, 인쇄 전에 내 휴대폰으로 읽어 확인하시기 바랍니다.

#segno #와이파이QR #QR코드만들기 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 파이썬(python.org, 설치 화면에서 "Add python.exe to PATH" 체크)을 설치한 뒤 명령 프롬프트에 py -m pip install segno 를 붙여넣어 설치합니다. 그다음 segno "WIFI:T:WPA;S:공유기이름;P:비밀번호;;" -o 와이파이.png --scale 10 을 입력하면 같은 폴더에 QR 그림이 생깁니다. 두 번 눌러 쓰는 실행 파일(.bat)과 오류 해결법은 롱폼 설명란의 저장소 링크에 있습니다!
```
