# 롱폼: 명령 창 한 줄로 일기 끝 — 무료 일기장 jrnl (약 5분 6초 · 어림 시간)

**영상 상태**: 장면 코드(`demo/render/scenes.js`, 롱폼 14개 장 모두 직접 만듦 + 냥봇)까지 완료. **mp4는 운영자가 대사를 점검·녹음한 뒤 '영상 제작 단계'에서 렌더링**합니다(2026-11-25 운영자 요청, 저장소에 커밋하지 않음). 아래 챕터 시각은 대본 어림값(초당 6.3글자)이라 **음성 버전을 만든 뒤 다시 맞춥니다.**

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**제목** (하나 골라서 복사)
```
명령 창 한 줄로 일기 끝 — 날짜가 저절로 붙는 무료 일기장 jrnl 사용법 (설치법 포함)
```

**설명란** (통째로 복사 · 챕터 시각은 음성 버전 렌더링 후 바꿔 넣기)
```
명령 창에 한 줄 쓰면 날짜·시간을 붙여 저장하고, 꼬리표·날짜·글자로 다시 찾아 주는 무료 일기장 jrnl(제이알엔엘)을 소개합니다.
한 줄 쓰기, 영어 날짜 말, @꼬리표 찾기, 마크다운 내보내기, 암호 자물쇠, 가상 일기 10년치 3,650개 찾기까지 클라우드 시연 결과로 보여 드립니다.

▶ 원본 저장소: https://github.com/jrnl-org/jrnl · 공식 문서: https://jrnl.sh
▶ 명령어·시연 코드: https://github.com/codekimmy/daily-github-pick/tree/main/2026-11-25-jrnl
▶ 명령어 (cmd) — 도움말 기준, Windows 실행은 시연하지 않음 (파이썬 3.11~3.14 먼저 설치)
   py -m pip install jrnl        (설치)
   py -m jrnl "점심은 김치찌개였다. @점심"        (지금 시각으로 한 줄 쓰기, 처음엔 질문 3개 → 모르면 Enter)
   py -m jrnl "yesterday: 친구 생일 파티. @모임"        (어제 날짜로 쓰기, 날짜 말은 영어·숫자만)
   py -m jrnl @점심        (꼬리표로 찾기)
   py -m jrnl -contains 김치 --short        (글자로 찾기, 제목만)
   py -m jrnl --format md --file 일기.md        (마크다운 파일로 내보내기)
   py -m jrnl --encrypt        (암호 걸기 — 암호를 잊으면 되살릴 수 없음)
▶ 명령어 없이 쓰기: 저장소 폴더의 demo/tools_win/한줄일기.bat를 두 번 누르면 한 줄을 묻고 저장한 뒤 최근 일기 5개를 보여 줍니다 (파이썬·jrnl 설치 먼저)
▶ Windows 설치·실행·오류 해결 전체 순서는 위 저장소 링크의 README 'Windows에서 쓰는 법'에 있습니다
※ 읽는 법: 영상 속 시간(0.15초·0.34초)은 명령을 입력하고 결과가 나올 때까지 걸린 전체 시간(프로그램을 켜는 시간 포함)이며, CPU 2개 클라우드 기준입니다.
※ 일기 내용과 암호는 시연용 가상 자료입니다.

※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-25 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- jrnl 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 공식 저장소에서만 받으시기 바랍니다.
- 암호를 잊으면 잠근 일기를 되살릴 수 없습니다. 암호는 따로 적어 두고 일기 파일은 따로 백업하시기 바랍니다.
```
