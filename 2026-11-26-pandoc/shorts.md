**영상 상태**: 장면 코드(`demo/render/scenes.js`, 숏폼 5장면 모두 직접 만듦 + 냥봇)까지 완료. mp4는 운영자 대사 점검·녹음 뒤 영상 제작 단계에서 렌더링합니다(저장소에 커밋하지 않음). 아래 시간은 어림값이라 음성 버전에서 다시 맞춥니다.

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
메모장 글이 0.04초 만에 워드 문서로 — 20만 자 보고서도 0.37초, 무료 문서 변환기 pandoc
```

**설명란**
```
무료 문서 변환기 pandoc은 메모장에 마크다운으로 쓴 가상 회의록을 명령 한 줄로 0.04초 만에 제목·표가 든 워드 문서로 바꿨고, 같은 글을 파워포인트 5장·전자책·웹페이지로도 바꿨습니다. 20만 자짜리 가상 보고서는 0.37초 만에 140쪽 워드 문서가 됐습니다.
읽는 법: 시간은 명령을 입력하고 pandoc이 끝날 때까지 걸린 전체 시간(CPU 4개 클라우드 기준), 쪽수는 LibreOffice로 연 기준이고, 문서는 시연용 가상 자료입니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 한글 문서(HWP)는 지원하지 않고 같은 이름의 결과 파일은 묻지 않고 덮어쓰므로, 원본은 따로 보관하시기 바랍니다.

#pandoc #문서변환 #워드 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 명령 프롬프트에 winget install --id JohnMacFarlane.Pandoc 을 붙여넣어 설치하고, 명령 창을 새로 연 뒤 pandoc 회의록.md -o 회의록.docx 처럼 쓰면 됩니다. PDF는 typst를 따로 설치해야 합니다. 끌어다 놓는 실행 파일(.bat)과 오류 해결법은 롱폼 설명란의 GitHub 저장소 링크에 있습니다!
```
