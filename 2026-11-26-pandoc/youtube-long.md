▶ 명령어 (cmd) — 도움말 기준, Windows 실행은 시연하지 않음
   winget install --id JohnMacFarlane.Pandoc        (설치, 설치 뒤 명령 창을 새로 열기)
   pandoc 회의록.md -o 회의록.docx        (메모 → 워드)
   pandoc 회의록.docx -t gfm -o 회의록_글.md        (워드 → 마크다운 글)
   pandoc 회의록.md -o 회의록.pptx        (파워포인트)
   pandoc 회의록.md -o 회의록.epub        (전자책)
   winget install --id Typst.Typst        (PDF용 프로그램)
   pandoc 회의록.md -o 회의록.pdf --pdf-engine=typst -V mainfont="Malgun Gothic"        (PDF, 한글 글꼴 지정)
