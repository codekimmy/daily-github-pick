# 숏폼: 이 그림 속에 쪽지가 숨어 있다면? (약 47초 · 어림값, 세로 9:16)

**영상 상태**: 장면 코드(`demo/render/scenes.js`, 숏폼 5장면 모두 직접 만듦 + 냥봇)까지 완료. mp4는 운영자 대사 점검·녹음 뒤 영상 제작 단계에서 렌더링합니다(저장소에 커밋하지 않음). 아래 시간은 어림값이라 음성 버전에서 다시 맞춥니다.

## ✅ 업로드용 (이 부분만 복사해서 쓰면 됨)

**순서**: 롱폼을 먼저 올린 뒤, 쇼츠 업로드 화면의 **"관련 동영상"**에 롱폼을 연결 (쇼츠는 설명란·댓글 주소를 눌러 이동할 수 없음)

**제목**
```
평범한 그림 속에 쪽지가? 0.22초 만에 숨기고 0.17초 만에 꺼내는 무료 프로그램 Stegano
```

**설명란**
```
무료 프로그램 Stegano는 코드로 그린 가상 그림에 깜짝 파티 쪽지를 0.22초 만에 숨겼고, 꺼내기 명령은 0.17초 만에 쪽지를 그대로 보여 줬습니다. 바뀐 점은 0.02%, 색 번호도 한 칸씩만 바뀌어 눈으로는 구분할 수 없습니다.
읽는 법: 시간은 명령을 입력하고 끝날 때까지 걸린 전체 시간(클라우드 기준)이고, 그림·쪽지는 가상 자료입니다. Windows 설치법은 전체 영상(관련 동영상)에서 확인하시기 바랍니다.

※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
※ 숨기기일 뿐 암호화가 아니어서 누구나 꺼낼 수 있고, JPG로 바꾸면 쪽지가 사라지므로 비밀번호·개인정보는 넣지 마시기 바랍니다.

#stegano #스테가노그래피 #비밀쪽지 #shorts
```

**고정 댓글** (업로드 후 댓글로 달고 '고정')
```
Windows는 파이썬을 먼저 설치하고(winget install Python.Python.3.13), 명령 창을 새로 연 뒤 py -m pip install stegano 로 설치합니다. 그다음 stegano-lsb hide -i 사진.png -m "쪽지" -o 비밀.png 처럼 쓰면 됩니다(결과는 꼭 .png). 끌어다 놓는 실행 파일(.bat)과 오류 해결법은 롱폼 설명란의 GitHub 저장소 링크에 있습니다!
```
