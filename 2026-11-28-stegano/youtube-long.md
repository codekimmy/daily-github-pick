# 롱폼: 이 그림 속에 쪽지가 숨어 있습니다 — 무료 스테가노그래피 프로그램 Stegano (약 5분 45초 · 어림값)

**영상 상태**: 장면 코드(`demo/render/scenes.js`, 롱폼 14개 장 모두 직접 만듦 + 냥봇)까지 완료. **mp4는 운영자가 대사를 점검·녹음한 뒤 '영상 제작 단계'에서 렌더링**합니다(2026-11-25 운영자 요청, 저장소에 커밋하지 않음). 아래 챕터 시각은 대본 어림값(초당 6.3글자)이라 **음성 버전을 만든 뒤 다시 맞춥니다.**

▶ 명령어 (cmd) — 도움말 기준, Windows 실행은 시연하지 않음
   winget install Python.Python.3.13        (파이썬 설치, 설치 뒤 명령 창을 새로 열기)
   py -m pip install stegano        (Stegano 설치)
   stegano-lsb hide -i 사진.png -m "토요일 3시 공원 정문" -o 비밀.png        (쪽지 숨기기, 결과는 꼭 .png)
   stegano-lsb reveal -i 비밀.png        (쪽지 꺼내기)
   stegano-lsb hide -i 사진.png -f 쪽지.txt -o 쪽지그림.png        (파일 통째로 숨기기)
   stegano-lsb reveal -i 쪽지그림.png -o 꺼낸쪽지.txt        (숨긴 파일 꺼내기)
▶ 명령어 없이 쓰기: GitHub 저장소 폴더의 demo/tools_win/비밀쪽지.bat 위에 그림을 끌어다 놓으면 쪽지를 숨기거나(이름_비밀.png) 꺼낼 수 있습니다 (파이썬·Stegano 설치 먼저)
▶ Windows 설치·실행·오류 해결 전체 순서는 위 GitHub 저장소 링크의 README 'Windows에서 쓰는 법'에 있습니다
※ 읽는 법: 영상 속 시간(0.22초·0.17초)은 명령을 입력하고 끝날 때까지 걸린 전체 시간(클라우드 기준)이고, 색 번호 '1칸'은 0~255 사이 번호가 150에서 151로 바뀌는 정도입니다.
※ 그림은 코드로 그린 가상 그림, 쪽지는 시연용 가상 쪽지입니다.

※ 유의사항
※ 이 영상은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.
- 영상 속 결과는 2026-11-28 클라우드 환경(리눅스) 시연 결과로, 운영자가 직접 검증한 것이 아니며 내 PC에서는 다를 수 있습니다.
- Stegano 제작자와 관련 없음(광고·제휴 아님). 설치·사용 책임은 본인에게 있습니다. 공식 GitHub 저장소·PyPI에서만 받으시기 바랍니다.
- 숨기기일 뿐 암호화가 아니어서 누구나 꺼낼 수 있습니다. 비밀번호·개인정보는 넣지 말고, JPG로 바꾸면 쪽지가 사라진다는 점을 기억하시기 바랍니다.
