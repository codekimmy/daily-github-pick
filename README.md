# daily-github-pick 🗺️

**매일 GitHub 인기 오픈소스 하나를 골라, 실제로 설치·실행해 확인하고, 초보자 눈높이로 소개합니다.**

하루치 폴더마다 이렇게 들어 있어요.

| 파일 | 용도 |
|---|---|
| `README.md` | 팩트시트 + 테스트 기록 + Windows 명령어 (원본) |
| `blog.md` | 티스토리 소개글 — 마크다운 모드로 복붙 |
| `youtube-long.md` | 유튜브 롱폼 대본 + 장면 지시 + 챕터 |
| `shorts.md` | 유튜브 숏폼 60초 대본 + 자막 |
| `media/` | 터미널 녹화 GIF, 결과 화면 영상(가로·세로), 캡처 |
| `demo/` | 직접 만든 데모 코드 |
