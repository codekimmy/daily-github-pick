# mp4 영상을 GIF로 바꾸는 법, 무료 프로그램 ffmpeg 사용법 총정리 (Windows cmd)

※ 이 글은 오픈소스 프로젝트를 소개하는 정보 제공용이며, 특정 프로그램 사용을 권하거나 결과를 보장하지 않습니다.

> **한 줄 요약** — 무료 프로그램 ffmpeg를 설치하면, 명령 한 줄로 mp4 영상을 움직이는 그림(GIF)으로 바꿀 수 있습니다.
> 무료 오픈소스 · LGPL/GPL 라이선스 · Windows·맥·리눅스

> **일반인 쓸모 ★★★★☆** — 설치 명령 한 줄, 변환 명령 한 줄이면 됩니다. 창(버튼) 화면이 없고 명령이 길어서 별 하나를 뺐습니다.
> **이걸로 할 수 있는 것**
> 1. 휴대폰으로 찍은 **짧은 영상을 GIF로** 만들어 블로그·카톡에 올린다
> 2. 프로그램 사용 화면을 녹화한 mp4를 **설명용 GIF**로 만든다
> 3. 긴 영상에서 **앞 몇 초만 잘라** 가벼운 GIF로 만든다

## 1. ffmpeg란 무엇입니까?

**ffmpeg**(에프에프엠펙)는 영상·소리 파일을 다른 형식으로 바꿔 주는 무료 프로그램입니다. 누구나 무료로 쓰고 고칠 수 있게 공개된 **오픈소스**이고, 2000년부터 이어져 온 프로젝트입니다. 많은 영상 프로그램이 안에서 ffmpeg를 가져다 씁니다.

창이 뜨는 프로그램이 아니라 **명령 프롬프트(cmd)에 한 줄**을 넣어서 씁니다.

## 2. 비유로 쉽게 이해하기

ffmpeg로 GIF를 만드는 일은 **영상을 '플립북(넘기는 그림책)'으로 만드는 일**입니다.

1. **장 수 정하기** — 1초에 몇 장을 뽑을지 정합니다 (`fps=12` → 1초에 12장)
2. **종이 크기 정하기** — 그림 한 장의 가로 크기를 정합니다 (`scale=640` → 가로 640픽셀)
3. **물감 고르기** — GIF는 그림 한 장에 **256색까지만** 쓸 수 있습니다. 그래서 먼저 영상에 맞는 256색 물감 세트를 고르고(`palettegen`), 그 물감으로 칠합니다(`paletteuse`)

3번을 하지 않으면 ffmpeg가 정해 둔 기본 물감으로 칠합니다.

## 3. 시연 결과

1920×1080, 30초, 2.6MB짜리 mp4(화면 애니메이션)를 클라우드(리눅스, CPU 2개, ffmpeg 6.1)에서 자동으로 변환한 결과입니다.

| 설정 | 결과 GIF 용량 | 걸린 시간 |
|---|---|---|
| 30초 전체 · 가로 640 · 초당 12장 · 물감 고르기 O | **2.4MB** | 7.0초 |
| 앞 10초만 · 가로 480 · 초당 10장 · 물감 고르기 O | **0.8MB** | 1.5초 |
| 30초 전체 · 가로 640 · 초당 12장 · 물감 고르기 X | 1.2MB | 2.7초 |

- 길이·가로 크기·초당 장 수를 줄이면 용량이 크게 줄었습니다 (2.4MB → 0.8MB)
- 물감 고르기를 빼면 용량과 시간은 줄지만, 색은 기본 물감으로 칠해집니다. 어느 쪽이 나은지는 두 결과를 직접 열어 보고 고르시기 바랍니다
- 영상 내용(색이 많은 사진 영상인지, 단순한 화면인지)에 따라 용량은 크게 달라집니다

## 4. 사용 방법 (Windows cmd, 순서대로)

**명령 프롬프트 여는 법**: 키보드 `Windows 키` → `cmd` 입력 → Enter

```cmd
:: 1) ffmpeg 설치 (처음 한 번만)
winget install Gyan.FFmpeg

:: 2) cmd 창을 닫고 새로 연 뒤, 설치 확인 (버전 글자가 나오면 성공)
ffmpeg -version

:: 3) 영상이 있는 폴더로 이동 (예: 다운로드 폴더)
cd /d "%USERPROFILE%\Downloads"

:: 4) 변환 (영상.mp4 자리에 실제 파일 이름)
ffmpeg -i 영상.mp4 -vf "fps=12,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" 결과.gif

:: 5) 결과 열어 보기
start 결과.gif
```

**용량을 줄이고 싶을 때 (4번 대신)**
```cmd
:: 앞 10초만, 초당 10장, 가로 480px
ffmpeg -t 10 -i 영상.mp4 -vf "fps=10,scale=480:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" 작은결과.gif
```

**중간 부분만 자르고 싶을 때**
```cmd
:: 5초 지점부터 8초 동안
ffmpeg -ss 5 -t 8 -i 영상.mp4 -vf "fps=12,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" 중간.gif
```

> ⚠️ **막히는 곳 세 가지**
> - 1번에서 `winget`을 찾을 수 없다고 나오면 → Microsoft Store에서 **'앱 설치 관리자'**를 업데이트합니다
> - 2번에서 `ffmpeg`를 찾을 수 없다고 나오면 → cmd 창을 **닫고 새로** 엽니다
> - 파일 이름에 띄어쓰기가 있으면 → `"내 영상.mp4"`처럼 **큰따옴표**로 감쌉니다

## 5. 숫자 바꾸는 법

| 바꿀 곳 | 뜻 | 숫자를 줄이면 |
|---|---|---|
| `fps=12` | 1초에 몇 장 | 움직임이 뚝뚝 끊기고, 용량이 줄어듦 |
| `scale=640:-1` | 가로 픽셀 (`-1`은 세로를 비율에 맞춰 자동) | 그림이 작아지고, 용량이 줄어듦 |
| `-t 10` | 앞에서부터 몇 초 | 짧아지고, 용량이 줄어듦 |
| `-ss 5` | 몇 초 지점부터 시작 | |

블로그용이라면 **가로 480~640, 초당 10~12장, 10초 이내**에서 시작해 보고, 용량을 보며 조절하시기 바랍니다.

## 6. 자주 묻는 질문

**Q. 정말 무료입니까?**
A. 네. ffmpeg는 무료 오픈소스입니다 (LGPL/GPL 라이선스). winget으로 받는 것은 이 ffmpeg를 Windows용으로 묶어 둔 판입니다.

**Q. 영상이 인터넷에 올라갑니까?**
A. 아닙니다. 내 컴퓨터 안에서 변환합니다.

**Q. 원본 mp4는 어떻게 됩니까?**
A. 그대로 남습니다. GIF는 새 파일로 따로 생깁니다. 다만 결과 파일 이름이 이미 있으면 덮어쓸지 묻는데, 이때 `y`를 누르면 그 파일을 덮어씁니다.

**Q. 명령어 없이 하는 방법은 없습니까?**
A. 창 화면으로 쓰는 무료 오픈소스 **ScreenToGif**(Windows) 같은 프로그램도 있습니다.

## 마무리

설치 한 줄, 변환 한 줄이면 mp4가 GIF가 됩니다. 용량이 크면 **길이(`-t`) · 가로 크기(`scale`) · 초당 장 수(`fps`)**부터 줄여 보시기 바랍니다.
