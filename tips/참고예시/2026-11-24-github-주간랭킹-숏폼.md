# 참고 예시 분석 — GitHub 주간 탑텐 랭킹 숏폼 (2026-11-24 운영자 제공, 카카오톡 화면 녹화 152초)

- 형식: 세로 숏폼 약 80초가 2번 반복 재생된 화면 녹화(1080×2340, 30fps). 10위 → 1위 → 보너스 신인 → 탑텐 표 → 좋아요·팔로우 순서, 순위 하나에 6~8초·컷 2~3개
- 오디오 있음(평균 -9.9dB). 내레이션인지 음악인지는 확인 못 함

## 가져온 것 (연출 방식만) → tools/motion
| 참고 영상 연출 | 우리 쪽 구현 |
|---|---|
| 위 큰 자막 낱말이 차례로 튀어 오르고 핵심 낱말만 주황 | `M.caption` (*강조* + 노란 형광 밑줄) |
| 검은 테두리 스티커 카드(브라우저·체크리스트·채팅·코드 창) | `.card` + 카드별 내용 |
| 가짜 커서 클릭·타이핑·체크 표시 | `M.term` 타이핑, 결과 줄 ✓ |
| 빨간 펜 취소선·동그라미·손글씨("여기 다시!") | `M.pen`, `M.circleAround`, `M.hand` |
| 별 개수 카운트업, 0,000 → 31,095 숫자 | `M.count` |
| 막대그래프 마지막 막대가 빨갛게 솟음 + 반짝 선 | (다음에 필요할 때 `M.pen` 반짝 선 + 막대) |
| 장면마다 바탕색 바뀜(베이지·하늘·살구) + 점 무늬 | 장마다 바탕 5색 차례 |
| 큰 점(하프톤)으로 화면이 덮이며 전환 | `trans:'dots'` (검은 화면 없이 새 장이 점 모양으로 드러남) |
| 아래 '이번 주 탑텐 n/10' 진행 표시 | 맨 아래 영상 전체 진행 막대 |

## 가져오지 않은 것
- 주황 마스코트 캐릭터(남의 디자인, 우리 채널 캐릭터도 보류 중), 종이비행기 3D 접힘(구현 대비 효과 작음), 영상의 문구·순위 자료·음악
