# 참고 예시 (운영자가 보여 준 다른 곳의 제작물)

운영자가 대화에서 보여 준 다른 채널·블로그의 영상·글 예시를 정리하는 곳입니다 (2026-11-15 운영자 요청).

- 예시마다 `YYYY-MM-DD-짧은이름.md` 파일 하나: 출처 링크, 받은 캡처(같은 폴더의 그림 파일), 참고할 점(구성·화면 연출·자막·음성·썸네일·설명란 등), 지금 방식과 다른 점, 도입 방법 제안
- **저작권**: 다른 제작물의 영상·그림·문장·음악을 복사해 쓰지 않습니다. 구성과 연출 방식만 참고해 직접 만듭니다
- 매주 '영상 제작 방식 점검'이 이 폴더를 함께 읽고, 지금 방식과 비교해 도입할 만한 점을 제안합니다
- 도입하기로 정한 내용은 GUIDE.md 해당 장에 날짜와 함께 옮겨 적습니다
