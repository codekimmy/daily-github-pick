# 연출 아카이브 — 필요할 때 꺼내 쓰는 영상 효과 모음

> 2026-11-15 운영자 요청: 영상 제작에 활용할 가치가 있는 연출을 모아 두었다가, **오픈소스마다 어울리는 것만 골라** 꺼내 쓴다. 모든 영상에 다 넣지 않는다.
> 새 연출은 참고 예시(`tips/참고예시/`)·주간 점검(`tips/weekly-check/`)에서 찾아 여기에 더한다. 음성 속도·쉼은 GUIDE 5-1장 그대로(아카이브 대상 아님).

## 쓰는 법
1. 그날 오픈소스의 결과가 어떤 종류인지 본다 (속도·숫자 / 전·후 비교 / 단계·흐름 / 여러 설정 비교 / 화면 앱 …)
2. 아래 표의 **어울리는 오픈소스** 칸을 보고 1~3개를 고른다 (억지로 넣지 않음)
3. 공용 코드(`kit.js`)는 그날 `demo/render/page.html`에 `<link rel="stylesheet" href="../../../tools/kit/kit.css"><script src="../../../tools/kit/kit.js"></script>`로 불러 쓰고, 날짜 폴더에만 있는 연출은 그 폴더 코드를 복사해 고쳐 쓴다
4. 쓴 연출은 아래 **사용 기록**에 한 줄 남긴다 (어느 날 무엇에 썼는지 → 다음에 고를 때 참고)

## 공용 코드 (`kit.js`, 시범 영상 `kit-demo.mp4`)
| 연출 | 함수 | 어울리는 오픈소스 | 주의 |
|---|---|---|---|
| **체감 카운터** — "이 영상 보는 동안 +N쪽" 재생 시간만큼 숫자가 오름 | `KIT.watchCounter` | 처리 속도가 빠른 도구 (변환·압축·OCR·잡음 제거: "보는 동안 +N분 녹음") | 1초당 값은 **시연 측정값으로만** 계산, 계산 근거를 화면에 적기 |
| **도장 배지** — 핵심 숫자를 비스듬히 '쾅' | `KIT.stamp` | 결과가 숫자 한두 개로 요약되는 것 ("9개 모두 찾음", "29dB↓", "15가지 중 10가지") | 장면당 1개, 영상 전체 2~3개까지 |
| **장 번호 카드** — 노란 전체 화면 "01 제목" | `KIT.chapterCard` | 시연이 여러 갈래인 롱폼(설치 → 시연 ①②③ → 아쉬운 점), 숏폼은 갈래가 뚜렷할 때만 | 장 사이 쉼(1.7초) 안에서 1~1.2초만 |
| **픽셀 조각 전환** — 칸 단위로 다음 장면이 나타남 | `KIT.dissolve` | 픽셀·이미지·게임·레트로 분야 (도트 그림, 글자 효과, 8비트 게임) | 다른 분야는 기존 크로스페이드가 무난 |
| **장면 틀 통일** — 위 작은 꼬리표 + 큰 제목 | `KIT.head` | 장면 수가 많은 롱폼 전반 | 자막 상자(아래)와 겹치지 않게 |
| **질문형 마무리** — 말풍선 질문 + "댓글로 알려 주시기 바랍니다" | `KIT.askEnd` | 생활 습관과 이어지는 도구 ("스캔 서류 어떻게 보관하십니까?", "회의 녹음 어디에 쓰십니까?") | 엔딩 유의사항 문구(GUIDE 6-1)와 함께 |
| **바탕 격자 + 픽셀 제목 글꼴** (갈무리, SIL OFL 1.1) | `KIT.bg`, `KIT.PIXEL_B` | 레트로·게임·터미널 분위기 도구 | 자막·본문은 Noto Sans CJK 유지 |

## 후보 (주간 점검 제안, 운영자 확인 전)
| 연출 | 어울리는 오픈소스 | 확인 | 근거 |
|---|---|---|---|
| **코드 변신** — 전·후 코드에서 같은 낱말은 미끄러져 자리 이동, 빠진 낱말은 흐려지고 새 낱말은 나타남 + 바뀐 줄 형광펜 | 파이썬·JS 라이브러리, 설정 파일·명령어 옵션 비교 ("옵션 한 줄 더하면 결과가 이렇게") | HyperFrames `code-morph` 블록을 CPU로 렌더링해 동작 확인(1080p 7초 → 17초). 우리 page.html 구현은 아직 | `tips/weekly-check/2026-11-16.md` |
| **말하는 자리 형광 자막** — 자막 상자는 그대로, 문장 안에서 지금 읽는 낱말까지 노란 띠가 차오름(문장 실제 음성 길이 × 글자 수 비례) | 숏폼 전반(설명·비유 장면), 롱폼은 미리보기 정도 | 세로 캔버스 한글 시범 프레임 확인. 실제 음성과 맞춘 확인은 아직 | `tips/weekly-check/2026-11-16.md` |
